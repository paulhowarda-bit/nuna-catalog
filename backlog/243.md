## What was done

Console only (`rules.js`, new; `panels.js`, `api.js`, `governance.js`, `style.css`), in Atelier's words:

- **The panel.** A table's Access tab has "Row filters and column masks" between Governance and Grants, for callers
  whose groups hold manage-grants or manage-tags in the catalog; nobody else is asked. Not flagged, it says "Rules need
  the flag. …"; flagged with no rules, "Flagged. No rules yet: …".
- **Grant admin.** The list (Group | Rows | Masked columns | Set by, when | Edit, Remove) from the rules route, and "Add
  a rule for a group". A rule for one of the caller's own groups (from the token) has no buttons: "Another grant admin
  sets this group's rule."
- **The dialog.** Group (fixed when editing); Rows, "Every row" or "Only rows where" with a predicate; one line per
  masked column, the column from the schema route (backlog 242) and NULL, '***' or a custom expression. Before saving
  it checks the fields, the 4,000-character limit, each column in the schema and none twice. A rule with every row
  and no masks is sent with `row-filter` `true`, as the route asks. The first rule warns "Groups without a rule will
  see no rows." The 409 NotFlaggedException shows the not-flagged words; the separation-of-duties 403 shows "You belong
  to {group}. Another grant admin sets this group's rule."; every other refusal (backlogs 240 and 244 among them) as
  the catalog gives it.
- **Remove.** The confirm says "{group} will see no rows." while other rules stand, "Everyone with select will see
  every row through Trino." for the last.
- **Steward.** The rule count and groups from the table's governance answer, no expressions.
- **Reader.** "Your view of this table" under What you may do, on a flagged table, for a caller whose groups hold
  select or more on it: "Read through Trino only. Your rows are filtered. Masked for you: trader." from the `mine`
  route.
- **Governance page.** A fifth figure, "Flagged tables" with their rule total, and a "Flagged tables" panel listing
  each with its rule count, each row opening the table's Access tab.
