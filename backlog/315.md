- The Maintenance page's "Last night" time axis draws its labels over each other.
- `health.js:428` maps a source `default` to "built-in", but the server sends `built-in` for built-in values, so
  the mapping is dead and a real `default` would be misnamed.
- The merge preview says "Needs create on … and write on each table." (`refs.js:1120`), but views and definition
  changes need modify.
- The console's favicon is still the old "F" mark.
- `browse.js`'s header comment still names the old Governance and Grants tabs.

What done looks like: each fixed, or Atelier says why it stays.

## What was done

- The Last night chart labels its time axis every 1, 2, 3, 4, 6, 12 or 24 hours, the fewest that leave 56 px
  between labels, so two never meet however long the night or narrow the screen.
- `sourceWords` names the server's `built-in` source "built-in" (it had fallen to "this built-in") and its
  `default` source, the deployment's own maintenance defaults, "the server's default".
- The merge preview says it needs create on the catalog, write on each table it moves, and modify on each view and
  each table whose definition changes, as `RefRoutes.operation` judges; the missing-rights warning no longer says
  "write".
- The console's favicon is the documentation site's peak mark, the one the header draws.
- `browse.js`'s header names a namespace's tabs as they are: Contents, Access, Audit and Properties.

No test covers these (the console's browser tests are heavy); `ConsoleRulesTest` passes.
