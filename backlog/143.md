1. **Overview and Maintenance contradict each other before any assessment.** The overview's headline read "0 of 7
   tables in shape. Nothing queued for tonight." while its own legend said 7 "not yet assessed", and the In shape card
   "0 of 7 · none queued for tonight, 7 not yet assessed". Maintenance's headline read "Every table you may read in
   lakehouse is in shape." `GET /management/v1/maintenance/estate` leaves `assessment` out of a table's row until the
   worker has assessed it; the queue (`GET /management/v1/maintenance/tables`) lists only assessed tables that need
   compaction, so Maintenance, reading only the queue, took an empty queue for an estate in shape.
2. **Governance's subtitle names the wrong source.** It said "Classification arrives from the data catalogue and
   owners from the HR feed, each with where it was set." Since D27's amendment of 2026-11-22 (item 140), people set
   the four labels in the console; an outside tool can push them only if one is ever connected.

Done looks like: both pages say plainly how many tables are not assessed yet (all of them, or some) and never count
an unassessed table as in shape or out of shape; the Governance subtitle says the labels are set in the console; no
other console text says the labels come from a data catalogue or an HR feed (provenance values shown as data, such as
`demo-seed: HR feed`, stay); a heavy browser test reads the new wording on both pages.

What was done: the estate's row has no `assessment` until the worker reports on the table, and that is how both pages
now tell an unassessed table apart. `queue.js` has `shapeWords`, the one sentence both headlines use: "7 tables not
assessed yet: the maintenance worker has not reported." when none is assessed, "3 of 5 assessed tables in shape; 2 not
assessed yet." when some are, and "5 of 5 tables in shape." when all are. Maintenance now reads the estate beside the
queue: with tables queued its headline adds "1 not assessed yet.", with none it uses `shapeWords`, and a catalog with no
table the caller may select reads "No table in <catalog> is yours to select." as the overview does. The overview's In
shape card counts against the assessed tables only, and its and Maintenance's empty-queue text no longer say an
unassessed table needs nothing. Governance's subtitle says the four labels are set in the console and that an outside
data catalogue can push them if one is ever connected; no other console text said they came from a data catalogue or
an HR feed. `ConsoleHealthTest#aTableNotAssessedYetIsNeitherInShapeNorQueued` (heavy) reads the new wording on both
pages for a reader with some tables assessed and one with none; it has not run yet, as the fast build leaves it out.
