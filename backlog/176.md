  (`./gradlew build --profile`, with the nuna-demo stack rebuilding and 336 MB free). `:bitesApply` declares no inputs
  or outputs, so it runs `git apply --check` on all 571 bites in every build. CLAUDE.md says the fast build takes
  "under a minute" and the bites "about 20 s".
- The sessions of 2026-11-16 to 23 (their transcripts, mined by the test-expert agent's `mine_test_commands`) ran the
  whole fast build 78 times (48 timed: median 80 s, p90 231 s, max 311 s; 30 in the background), one session 15
  times, and `land.sh` 150 times. One module's tests took a median of 23 s.
- When `main` moves before `land.sh`, CLAUDE.md sends the branch back to merge and build again, even when `main` moved
  only in Markdown, which nothing the build reads is.

Done looks like:

- `:bitesApply` checks only the bites whose patch, or a file the patch touches, changed since the bites last applied,
  and does nothing when none did; a bite that does not apply still fails the build.
- CLAUDE.md says to test locally while working (the changed module's or class's tests) and to run the fast build once,
  at landing; its times are the measured ones.
- `land.sh` lands a branch whose build was green when `main` has moved since only in Markdown, merging it, without
  sending the branch back to build.
- The fast build measured again: with nothing changed, and after a change to one source file.

What was done, 2026-11-23:

- `:bitesApply` hashes each patch with the files its `diff --git` lines name, and runs `git apply --check` only on
  the bites with no marker for that hash in `~/.gradle/nuna/bites-applied`; a bite that applies leaves one. Whether a
  patch applies depends only on those bytes, so the markers hold for every worktree. A bite that does not apply leaves
  none and fails the build, as before.
- `land.sh` lands a branch when `main` has moved since its merge only in `.md` files, saying so; when `main` moved in
  any other file it refuses, naming up to three, with `main` as it was. A Markdown merge that conflicts stops in the
  merge and is undone, as any stopped merge was. `test-land.sh` checks these four cases in a scratch repository.
- CLAUDE.md: test locally while working and run the fast build once, at landing or for a batch; the measured times;
  the incremental bite check; `land.sh`'s Markdown case, in Landing and in the batch steps.
