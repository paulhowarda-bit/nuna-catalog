Item 10 gave `dr-reconcile` the option `accept-archived`, which reads every chain of the audit archive through
`ArchivedCommits.read`. That calls `ObjectLockArchive.events(chain, anchor)`, which joins every segment of the chain
into one byte array (`concatenate`) and decodes every record into one list before it returns. The audit topic carries
every record, reads, denials and credential issues included, and the archive keeps them at least five years (D23), so
a production chain will not fit in a server's heap. The drill and the tests read archives of a few thousand records.

Done when the reconcile's read verifies and filters each chain in one streamed pass, segment by segment
(`ArchiveVerifier` already reads an `InputStream`), keeping only the commit records, with a test over an archive in
memory (`MemoryS3`) whose chain is larger than the reader holds at once.

Done: `ArchivedCommits.read` checks each chain in one pass, segment by segment: `ObjectLockArchive` fetches a segment
(a streamed `GetObject` of its version) only once the one before it has been read to its end, holds one buffer of the
chain (`READ_BUFFER`, 64 KiB, a constructor argument tests set small) besides the record being checked, and hands
over each event once its record's hash checks; the read keeps only each chain's main-pointer swaps and a count of its
commit records, and counts them only once the chain verifies. The check is the one made before, through the same
`ArchiveVerifier` pass over the segments in order: same defects, same line numbers, no signature or Object Lock check
(the read made none before either). A chain broken part way yields nothing: the read throws as before. The order of
failure is kept: after a break the read still fetches the later segments, so one the store cannot serve fails the read
as unreadable (503) before the break fails it as broken (500), as when every segment was fetched before any was
checked; an undecodable event fails it only once the chain verifies. `verify` and `events` use the same pass.
`ReconcileRoutes` needed no change.
