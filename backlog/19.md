`build-plan.md`, UI v1, Open: each `GET .../audit` read opens a short-lived Kafka consumer. That is fine at console
rates; it needs a cap if scripts start using it.

Done when the route limits how often one caller (or all callers) may read, answering 429 beyond it, with a test.

What was done: one caller may read the audit trail at most `nuna.governance.audit-reads-per-minute` times in any
minute on a server, default 60, built as the purge limit is (`LifecycleRoutes`): the count is kept in the server's
own memory, so it is per replica, over a sliding minute. A caller is the principal the token names, or the end user
a trusted engine acts for (`Caller.subject()`). Beyond the limit the route answers 429 `TooManyRequestsException`
with `Retry-After: 60`, in the Iceberg error body the purge limit uses, without opening a Kafka consumer. As with
the purge limit, the 429 is not audited: it is no authorization decision (`Denial`) and reads nothing (`AuditRead`).
The slot is taken after the guard, the `limit` check and the topic check, so a refused or badly asked read takes
none. A caller with no read in the last minute is dropped from the count, so it holds only this minute's readers.

Why 60: the console reads only when a person opens an object's Audit tab, changes "latest N" or presses Refresh
(`detail.js`, `auditPanel`; no timer polls it), so a person comes nowhere near one read a second; a script is held
to that pace per server.

Tests: `AuditReadLimitTest`, Java only, the real route, guard and authorizer over a store double, a topic double and
a fake clock: reads up to the limit answered and audited; the next 429 with `Retry-After: 60`, no consumer opened, no
record; the minute slides one read at a time; two callers counted apart; refusals (403) and bad `limit` (400) take
no slot; the setting binds, defaults to 60, refuses 0. `GovernanceServer` sets the limit to 1000 so
`AuditReadRouteTest`'s 200 ms polling never meets it. Bite: `bites/UI/audit-read-unlimited.patch`, checked with
`git apply --check`, not run. Docs: `deploy/README.md`, Before production, "Audit-trail reads", says it is per
replica; `build-plan.md`'s UI v1 Open line says so too.

Not run tonight (heavy, Docker): `AuditReadRouteTest` and `ConsoleBrowserTest`, which read the route on the wire with
a real Kafka under `GovernanceServer`'s new setting. Nothing else is left.
