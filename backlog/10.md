checked against its hash chain before any record counts (`ArchivedCommits.read` in `catalog-audit`), before it walks
any table. Where no later file proves the next file, a swap the archive records from the file the walk has reached
decides (`Reconcile.plan`): its file is taken if storage holds it at the recorded version and SHA-256 (proof
`archived`). Two recorded swaps from one file, a recorded file storage does not hold as recorded, or an `accept`
entry naming another file stop the walk there; such entries are listed in `contradicted-accepts`. Where the archive
records nothing, `accept` decides as before. No archive answers 409, an unreadable store 503, a chain that does not
verify 500, with nothing applied. An archive record shows the swap committed on the primary (its outbox row is in
the swap's transaction, D23), not that its client got the answer: the standard the successor proof already uses.

skipped on `-Ps3=aws` (COMPLIANCE lock). `GovernanceWiring.java` was claimed but not changed; `deploy/README.md` has
