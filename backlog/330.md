What was done:

- What counts as a data change (`DataChanges`, my decision): a commit whose updates add a snapshot that appends,
  overwrites or deletes rows (Iceberg's `append`, `overwrite`, `delete`, or a snapshot naming no operation, which
  nothing proves left the rows alone); one that merges a catalog branch; one that moves `main` to another snapshot
  without adding one (a rollback or a fast-forwarding cherry-pick); and a registration or revive of a metadata file.
  Not one: a `replace` snapshot (compaction and manifest rewrites hold the same rows in other files, and counting it
  would name the worker again after every compaction), a commit adding no snapshot (expiry, schema, spec, sort order,
  properties, a ref other than main), and a create. Deletes count: a CDC delete changes what readers see.
- Server, no schema change: the tables listing (`NamespaceTablesRoutes`) gives each row `last-data-change`, found by
  reading the journal down from the row's version, 50 entries a read, among the newest 200 commits at most (left out
  when none of them changed data); each namespace's totals give `newest-data-change`. `last-commit` and
  `newest-commit` are as they were. A commit a maintenance principal made as itself carries `"maintenance": true`
  there and in the metadata log (`LifecycleRoutes`), from `nuna.security.maintenance-principals` through a new
  `Authorizer.maintenance(principal, endUser)`. Through a branch's own pointer the search reads the branch's own
  journal only. `docs/observability/namespace-tables.md` says all of this and the cost.
- Console: Contents' column is "Last data change" ("Last data change here" through a ref), and a namespace row shows
  its newest data change; a table with commits but no data change among its newest 200 shows a dash with that in the
  title. History folds a run of two or more expiry-only commits (remove-snapshots, with only the removals an expiry
  makes beside it) by one principal on one line into one row: "Snapshots expired 12 times", the span "19:00 to
  19:55", the versions, "nuna maintenance", and Show 12 / Hide, which opens the commits (Atelier's amendment). A run
  carries on across pages, and History reads on until it shows ten rows or four pages, so it leads with data changes.
  The worker reads "nuna maintenance" wherever a commit names it (History, Overview's current snapshot, Contents),
  its principal in the title.
