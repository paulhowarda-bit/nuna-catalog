# 33. The Keycloak account page fails for every demo user

Status: open
Added: 2026-11-15 by local_d697e3a0-9dcf-4401-b754-2b759dcc6b79
Touches: demo/k8s/keycloak-realm.json demo/README.md demo/demo.sh

Paul (2026-11-15) opened <http://localhost:8180/realms/keel/account>, which `demo/README.md` and the sign-in text
`demo.sh` prints give for signing out of Keycloak to change user, and got "Something went wrong / Sorry, an unexpected
error has occurred".

The page signs in, but Keycloak's account API answers its token with 401 (`/realms/keel/account/supportedLocales`
and `/realms/keel/account/?userProfileMetadata=true`, seen in the browser's network log). Users imported from
`demo/k8s/keycloak-realm.json` get no roles: `kcadm.sh get-roles -r keel --uusername ana --effective` lists none,
neither `default-roles-keel` nor the `account` client's `view-profile` and `manage-account`, which a user made in the
admin console gets by default. Without them the account console's token is not addressed to the account API.

Done when each demo user in the realm file holds `default-roles-keel`, the account page loads for them, the
console's and kafbat's tokens are unchanged, and the README and `demo.sh` send people to Keycloak's logout page
(`/realms/keel/protocol/openid-connect/logout`), which signs out in one click.
