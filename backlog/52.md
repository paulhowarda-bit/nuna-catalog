# 52. backlog.sh done fails on a branch name with a slash

Status: open
Added: 2026-11-15 by obs38 session
Touches: backlog.sh

`./backlog.sh done <n>` marks the item with `sed -i "s/^Status: open\$/Status: done\nDone: $today on $branch/"`
(`cmd_done`). The desktop app's worktree sessions are on branches named `claude/<name>`, so the slash in `$branch`
ends the sed expression early: on 2026-11-15, on `claude/obs38-telemetry-base-e74d58`, it printed
`sed: -e expression #1, char 59: unknown option to 's'`, left the item open, and still said it had marked it done.

Done when `done` marks an item on a branch whose name holds a slash (use a delimiter a branch name cannot hold, or
escape it), fails loudly when the edit does not take, and `backlog/README.md` needs no change.
