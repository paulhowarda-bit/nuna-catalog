Done. Two causes, the second hidden behind the first.

1. Podman drops the image's health check. `singlestoredb-dev:0.2.88` is published as an OCI image
   (`application/vnd.oci.image.manifest.v1+json`); its Dockerfile's `HEALTHCHECK CMD-SHELL /scripts/healthcheck.sh`
   (5 s interval, 5 s timeout, 90 s start period, 3 retries) shows in the image's history, but
   `podman image inspect --format '{{json .Config.Healthcheck}}'` prints `null`, and so did a container started from it
   (`.State.Health` null). Docker Desktop read the check from the OCI config, so the test passed every night through
   2026-11-25 (98 to 110 s); 2026-11-27 was its first night under Podman (Docker Desktop gone 2026-11-26). With no
   health to report, `Wait.forHealthcheck()` ran its 5 minutes out, although the container's own log shows SingleStore
   configured and Studio listening 45 s after start. Not memory: the Podman machine had 6.7 GB available
   (`podman-info.txt`) and 6.2 GB on 2026-11-27 afternoon. The same image run by hand with the same check given at
   create time (`--health-cmd /scripts/healthcheck.sh ...`) reported `healthy` after 25 s. The demo is not affected:
   its pod runs `/scripts/healthcheck.sh` as its own startupProbe (`demo/k8s/singlestore.yaml`).
2. Backlog 280's sweep (4235acea, 2026-11-25 20:35) made the root password per run but left `connect()` logging in
   with the old literal `it-root`, so once the container was healthy every statement got `Access denied for user
   'root'`. It landed after the last green night, and the health check hid it on 2026-11-27.

Fix, both in `ChangeFeedTest`: the container is created with the image's health check given explicitly (the same
command and timings, so Docker and Podman behave alike), and `connect()` uses `ROOT_PASSWORD`. No other test waits on
an image's own health check; `EngineMatrixTest` runs this image in kind under the demo's probe.

Checked on 2026-11-27, beside the nuna-demo stack and two other sessions' test stacks (Podman machine 4.9 GB
available, Windows 147 MB free): `./gradlew :singlestore-change-feed:test --tests '*ChangeFeedTest' -Pheavy`, 7 tests,
0 failures, 98.9 s, the container healthy in 36 s; `./gradlew build` green. Left: the item closes when the overnight
run's heavy build passes it.
