# 140. Console: set owner, retention class and regulated, as it sets classification

D27, amended 2026-11-22: nuna is the catalog, and its console is where people set the labels it enforces. The console
sets only one of the four. Its governance tab (`panels.js`, `governanceTab`) has "Set a classification", which `PUT`s
`/attributes/classification` with provenance `console`; owner, retention class and the regulated flag can be set only
through the push API, by a script or an outside tool.

Evidence:
- `panels.js` `classify` is the only caller of `api.setAttribute`.
- The route already takes every pushed kind (`GovernanceRoutes.PUSHED`: classification, owner, retention-class,
  regulated, row-column-policy), each with `manage-tags` on the target and an audited, provenanced record.
- What each accepts (`GovernanceRoutes.check`): classification and owner any non-empty text up to 1,000 characters;
  retention-class only a class configured in `nuna.governance.retention-classes`, refused with 400 naming the
  configured ones otherwise; regulated `true` or `false`.
- What each does: the owner and classification are labels engines receive on every load (D27, amended 2026-11-12);
  a retention class sets the youngest snapshot any commit or maintenance job may remove from a table beneath it (D11,
  D30), so it means nothing on a view; regulated on any level closes every table beneath it that has no
  classification of its own (`Authorizer.decide`), and the governance summary counts a regulated area only where
  the flag is set (`GovernanceSummary`), on the catalog or a namespace.
- The console cannot offer the retention classes: no route names them.

What done looks like:
- The governance tab offers, beside the classification, the owner (catalog, namespace, table, view), the retention
  class (catalog, namespace, table: chosen from the configured classes, each with its minimum snapshot age) and the
  regulated mark (catalog and namespace: marked or cleared). Each dialog says in plain words what the label does and
  that it is recorded as set from the console, with the caller's name, in the audit trail.
- The governance answer (`GET …/governance`) lists the configured retention classes with their minimum ages.
- A fast route test for that list; a browser test (`heavy`) that sets each label from the console and reads it
  back with provenance `console`.
