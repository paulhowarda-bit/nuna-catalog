Paul (2026-11-15): "Is it possible to setup all the demo tech to use keycloak so I dont have to login many times."
The console and kafbat sign in through Keycloak; CloudBeaver (localhost:8185) and SingleStore Studio
(localhost:8183) each ask for a password of their own.

- CloudBeaver Community has no OIDC sign-in, but it takes a user from a trusted reverse proxy's headers
  (`reverseProxy` provider, Community included: the docs' raw page is marked `products: [CE, EE, AWS, TE]`).
- Studio 4.1.1 has a SAML sign-in that its public docs do not describe: a `samlConfig` block in a cluster of its
  state file (`samlIdpMetadaUrl`, `samlAssertionAudience`) turns `samlEnabled` on, and `/api/saml-login` redirects
  to the IdP. Its page then connects with the person's name and the IdP's SAML response as the password, which
  SingleStore 10.9 checks itself (users `IDENTIFIED WITH authentication_saml`, `saml_*` settings in memsql.cnf).

Done when ana, gary, stella and oscar, signed in once through Keycloak, open CloudBeaver and Studio without
another password and with the rights they have now; nobody gets in to either without Keycloak; SingleStore checks
the signature of every SAML response; and the README, `demo.sh`'s sign-in text and install-at-work's image list say
so.
