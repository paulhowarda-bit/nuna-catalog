Install

Install the catalog server, the maintenance worker and the audit tables writer on Kubernetes with their Helm charts, beside a database, an object store and an identity provider you already run.

There are four ways in. To look around, start the demo (Run nuna on your laptop), which runs everything on your machine with made-up data. To try the charts, run the catalog on a local kind cluster with throwaway PostgreSQL, Kafka and Silo (Run nuna on a local kind cluster). For a production cluster, follow the pages below in order: check the requirements, build and push the images, prepare the database, the object store and the identity provider, install the catalog server, then the maintenance worker and, if you want the audit tables, the audit tables writer, and finish by checking the install. On a network with no outbound access, read Install on a locked-down network first: it says what to mirror before you start.

  • Requirements What must exist before you install: Kubernetes, Helm, a database, an object store, an identity provider, the network paths and the sizes.
  • Container images Build the three images from source and push them to your registry.
  • Install the catalog server with Helm Write the chart's config and secrets, install the release and read what the chart refuses.
  • Install the maintenance worker Give the worker its own identity in the catalog, the identity provider and each store, then install its chart.
  • Install the audit tables writer Write every audit record into the audit catalog's tables, from Kafka or from the server's log.
  • Use PostgreSQL The database, role and privileges, a client certificate in place of a password, and the start-up self-check.
  • Use CockroachDB The cluster settings and privileges the server checks before it starts on CockroachDB.
  • Use Oracle The service, Transaction Guard, the grants and the journal's Scheduler job.
  • Use MongoDB The replica set, the connection string and the write concern the server needs.
  • Set up object storage Buckets, prefixes and storage profiles on AWS S3, Ceph or Silo, and the role the server vends credentials from.
  • Reach AWS with IAM Roles Anywhere What is known about signing in to AWS with certificates in place of keys.
  • Connect an identity provider Trusted issuers, the groups claim, the operator and grant admin groups, and the console's sign-in client.
  • Send telemetry Send metrics, traces and logs to an OpenTelemetry collector.
  • Run nuna on a local kind cluster Try the charts on your machine with deploy/kind/kind.sh and deploy/local/run.sh on Podman.
  • Install on a locked-down network Mirror images and Maven repositories, trust an internal certificate authority and build with no outbound access.
  • Check the install Read the health routes and the self-check, then create, load and drop a first table through two servers.
  • Upgrade nuna Roll a new image one server at a time while the first new server migrates the schema.
  • Uninstall nuna Remove the releases, and know what stays in the database and the object store.
