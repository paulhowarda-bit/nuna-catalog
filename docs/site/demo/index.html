The local demo

The demo runs nuna and the services around it on a one-node kind cluster on your laptop, with sample data, for trying nuna and showing it. It is not a production install: it uses test keys, developer tokens and a certificate authority of its own.

demo/demo.sh up builds nuna from your checkout and starts the core: PostgreSQL as the server's database, Silo as the object store, Keycloak as the identity provider, the server with its console, the maintenance worker, the audit tables writer, and Trino with CloudBeaver as its web page. Five switches add the rest, each on with demo/demo.sh switch and off with demo/demo.sh switch stop: gen, a simulated broker-dealer writing live data; ss, SingleStore synced with Iceberg both ways; kafka, Kafka and Kafka Connect; cdc, change data capture from three databases; and metrics, Grafana with Prometheus and Tempo. Everything runs in namespace nuna-demo of context kind-nuna, behind one front door that serves every port over HTTPS on localhost.
