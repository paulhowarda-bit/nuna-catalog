An endpoint

POST /management/v1/catalogs/{catalog}/grants

Grants one privilege on one object to one group.

Needs manage-grants on the object Audited

Parameters

NameInTypeRequiredDescription
catalogpathstringYesThe catalog's name.
page-sizequeryintegerNoMost items in one page. Default 100.

Request body

{"group": "trading-analysts", "privilege": "select", "on": ["equities"]}

Responses

StatusWhen
201The grant was made.
403The caller holds no manage-grants on the object.
409The grant would break separation of duties.

Example

curl -sS -X POST "$NUNA/management/v1/catalogs/trading/grants" -H "Authorization: Bearer $TOKEN" -d @grant.json

GET /management/v1/catalogs/{catalog}/grants

DELETE /management/v1/catalogs/{catalog}/grants

Revokes a grant.
