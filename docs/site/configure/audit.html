Audit settings

Set where the server sends its audit records and changes, and where it reads the audit tables and the archive.

For platform operators

Every audit record the server makes is written to the log nuna.audit, and that log is the record of audit. Kafka is optional: with nuna.audit.kafka-bootstrap-servers set, records also go to the audit topic and changes to the change stream, best effort. The queryable audit tables and the Object Lock archive are written by the audit tables writer (Audit tables writer settings); the settings here tell the server where to read them.

The audit log

Type
log level
Default
INFO (set in the server's own application.yaml)
Allowed values
TRACE, DEBUG, INFO
Environment variable
LOGGING_LEVEL_NUNA_AUDIT
Helm
config.logging.level.nuna.audit
Read by
the server
Restart
Needed

The level of the log every audit record is written to. The server refuses to start when it is coarser than INFO: logging.level.nuna.audit must be INFO or finer: every audit record is written to the log nuna.audit, and that log is the record of audit.

Records are written in Elastic Common Schema JSON on the console, as every log of the server is (logging.structured.format.console: ecs). Collect the container's output and keep it as the audit record.

Kafka

nuna.audit.kafka-bootstrap-servers

Type
string (host:port list)
Default
none: no audit topic or change stream
Environment variable
NUNA_AUDIT_KAFKABOOTSTRAPSERVERS
Helm
config.nuna.audit.kafka-bootstrap-servers
Read by
the server
Restart
Needed

The Kafka cluster for the audit topic and the change stream. Without it the server serves and vends as with it, writes audit records and changes to the log alone, and logs at start-up nuna.audit.kafka-bootstrap-servers is not set: audit records go to the log nuna.audit only, with no audit topic or change stream.

The server's Kafka clients connect in plain text: no setting gives them TLS or SASL.

When neither this nor nuna.audit.tables.catalog is set, a request for an object's audit records answers 503 Neither the audit tables (nuna.audit.tables.catalog) nor the audit topic (nuna.audit.kafka-bootstrap-servers) is configured on this server.

The archive

The audit tables writer writes a hash-chained archive of the log to an Object Lock bucket. The server reads it, to check it every hour (the first check a minute after start-up) and for disaster recovery reconciliation, wherever nuna.audit.archive.bucket is set. It needs no Kafka.

nuna.audit.archive.bucket

Type
string
Default
none: the server reads no archive
Environment variable
NUNA_AUDIT_ARCHIVE_BUCKET
Helm
config.nuna.audit.archive.bucket
Read by
the server
Restart
Needed

The Object Lock bucket the writer's nuna.audit-tables.archive.bucket names. The bucket must have been created with Object Lock, or the server refuses to start with archive bucket bucket has no Object Lock configuration or archive bucket bucket does not have Object Lock enabled.

Without it, a request to check an archived record answers 503 The audit archive is not configured on this server (nuna.audit.archive.bucket).

The audit catalog

The queryable audit tables live in a catalog of their own. At start-up the server grants that catalog's readers select and the writer's group create and write, as the actor nuna-configuration, each grant checked as the grants API checks it. Unset, it grants nothing; a group left unset gets nothing. Grant admins may add more grants later.

The audit catalog, such as nuna_audit. It must be declared in nuna.storage.catalogs, or the server stops with nuna.audit.tables.catalog names no catalog: name; declare it in nuna.storage.catalogs.

The console's catalog-wide audit feed reads the table events in it, about a minute behind the topic. Without it, those reads answer 503 The audit tables are not configured on this server (nuna.audit.tables.catalog).

Example

config:
  nuna:
    audit:
      kafka-bootstrap-servers: kafka.example:9092
      archive:
        bucket: nuna-audit-archive
        profile: onprem
      tables:
        catalog: nuna_audit
        readers: data-stewards
        writers: nuna-audit-writers
