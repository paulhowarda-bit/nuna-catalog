Audit tables writer settings

Point the audit tables writer at the catalog and its source, and set up the Object Lock archive.

For platform operators

The audit tables writer is its own program, nuna-audit-tables, installed by its own chart. It signs in to the catalog as its own principal, whose group holds create and write on the audit catalog and nothing else, and writes the table events with the credentials the catalog vends it. It takes the audit records from one source: the audit topic (kafka, the default) or the catalog's log over OTLP/HTTP (otlp). With the source otlp it can also write the Object Lock archive.

The token

The writer signs in by the OAuth 2 client-credentials grant, which Iceberg's client makes and renews. Without the token settings the writer stops with nuna.audit-tables.token: set endpoint, client-id and client-secret; without one of the three, with nuna.audit-tables.token needs endpoint, client-id and client-secret: the client-credentials grant.

Source otlp

The receiver takes POST /v1/logs, protobuf or JSON, keeps the records of the log nuna.audit and ignores the rest. A record is written once however late a copy of it comes. Records are answered when taken, before their commit: a writer that stops loses from the table what waits for its commit, at most a commit interval, but not from the catalog's log.

The archive

With a bucket set, every record the receiver takes is archived first, in one hash chain per catalog server run, with a locked checkpoint at least every checkpoint-interval. The archive needs the source otlp: nuna.audit-tables.archive.bucket is set, and nuna.audit-tables.source is kafka: the archive is fed from the catalog's log, so it needs the source otlp. The catalog reads the same bucket (nuna.audit.archive.*).

Example

config:
  nuna:
    audit-tables:
      catalog-uri: http://nuna-catalog.nuna.svc:8181/
      principal: nuna-audit-tables
      source: otlp
      token:
        endpoint: https://idp.example/realms/data/protocol/openid-connect/token
        client-id: nuna-audit-tables
      archive:
        bucket: nuna-audit-archive
        endpoint: https://s3.example
        ca-bundle: /etc/nuna/archive-ca/ca.crt
secrets:
  existingSecret: nuna-audit-tables-secrets
archiveCaConfigMap:
  name: storage-ca

The Secret holds nuna.audit-tables.token.client-secret, nuna.audit-tables.otlp.token and the archive's keys.
