Server settings

Set the REST surface's page sizes, caches and limits, the console's sign-in, the health page's peers and the server's logging.

For platform operators

The server's REST surface, the console's sign-in, the health page's peers, and the Spring Boot keys the server sets in its own application.yaml. Telemetry export takes the standard OTEL_* environment variables, which the charts set from their telemetry values (Send telemetry); there are no nuna.telemetry.* settings.

nuna.ui

The console signs in like any other API caller, with a token from the identity provider that the server checks against nuna.security.issuers. It is a public OIDC client: authorization code with PKCE, no client secret. Nothing here is secret: all of it reaches the browser through /ui/config.json.

nuna.ui.docs-url

Type
string: a path on the server, an http(s) URL, or none
Default
/docs/: the documentation this server serves
Environment variable
NUNA_UI_DOCSURL
Helm
config.nuna.ui.docs-url
Read by
the server
Restart
Needed

Where the console's documentation links go: the Docs button in its header, which opens the documentation of the page shown, the line in its keys dialog, the link on its sign-in screen, and the next step on a page your groups cannot use. The server serves this documentation under /docs/ with no sign-in, so the default works on a network with no way out. Set a URL to send readers to a copy hosted elsewhere; a value without a trailing slash gets one. Set none to hide every link. Any other value stops the server from starting.

nuna.health

Each server holds only its own meters, so the server a platform operator's browser reaches asks the others for theirs to fill the console's health page.

Spring Boot keys

The server's own application.yaml sets these. Override one only where this says so.

Spring Boot keys the server sets
KeyValueNotes
server.port8181The port the server listens on. The catalog chart's container port and probes assume 8181, so leave it.
spring.threads.virtual.enabledtrueRequests run on virtual threads.
spring.application.namenuna-catalogThe name in logs and telemetry.
spring.main.banner-modeoff
logging.level.nuna.auditINFOMust stay INFO or finer: Audit settings.
logging.structured.format.consoleecsLog lines go to standard output as JSON in Elastic Common Schema.
logging.level.loggerSpring Boot's defaultsSet any other logger's level, such as nuna.alerts.
