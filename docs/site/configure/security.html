Security settings

Name the token issuers the server trusts, how their claims become principals, the administrative groups and the Trino catalogs that get row and column rules.

For platform operators

Every request to the server carries a bearer token from a trusted issuer; there is no setting that turns authentication off, and the server issues no tokens of its own. These settings name the trusted issuers, how their claims map to a principal, the two administrative groups, and the maintenance principals. The console's own sign-in is set by nuna.ui.oidc.* on Server settings; nuna has no nuna.oidc.* settings.

Token issuers

The server takes each issuer's signing keys only from its jwks-uri: it does no OIDC discovery, and never trusts a key a token names. A token is accepted when its iss is one of these issuers exactly, its signature verifies with one of the issuer's keys under an allowed algorithm, its aud names one of the issuer's audiences, and the clock is inside its exp and nbf give or take nuna.security.clock-skew. A token with no exp is refused.

Type
list of issuers

none (required, at least one)

The trusted token issuers. The server refuses to start with none: nuna.security.issuers names no trusted token issuer; the catalog accepts no request without one. The catalog chart refuses to render with none: config.nuna.security.issuers needs at least one trusted token issuer.

Each issuer needs every field below; a missing one stops the server with a message naming it, such as nuna.security.issuers[].jwks-uri of issuer.

Administrative groups and principals

nuna.security.grant-admin-groups

Type
set of strings (group names)
Default
empty
Environment variable
NUNA_SECURITY_GRANTADMINGROUPS_N, one per entry, or NUNA_SECURITY_GRANTADMINGROUPS holding a comma-separated list
Helm
config.nuna.security.grant-admin-groups
Read by
the server
Restart
Needed

Groups that hold manage-grants on every catalog and nothing else: they grant and revoke, and see every catalog in the catalog list, but read no data by being grant admins.

No group may be both a grant admin and a platform operator; the server refuses to start with groups [group] are both grant admins and platform operators.

nuna.opa

nuna.opa.catalogs

Type
map of Trino catalog name to warehouse
Default
empty
Environment variable
NUNA_OPA_CATALOGS_TRINOCATALOG; the name is read in lower case and cannot hold a hyphen
Helm
config.nuna.opa.catalogs
Read by
the server
Restart
Needed

For Trino's OPA access control: each Trino catalog whose tables carry row filters and column masks, mapped to the warehouse it reads, as that Trino catalog's iceberg.rest-catalog.warehouse says: a catalog, or catalog@ref for one read through a branch or tag.

A Trino catalog not named here gets no rules from nuna: name every Trino catalog that reads nuna.

Example

config:
  nuna:
    security:
      issuers:
        - issuer: https://idp.example/realms/data
          jwks-uri: https://idp.example/realms/data/protocol/openid-connect/certs
          audiences: [nuna-catalog]
          algorithms: [RS256]
          user-id-claim: sub
          groups-claim: groups
          client-id-claim: azp
      grant-admin-groups: [grant-admins]
      platform-operator-groups: [platform-operators]
      maintenance-principals: [nuna-maintenance]
    opa:
      catalogs:
        trading: trading
        trading_dev: trading@dev
