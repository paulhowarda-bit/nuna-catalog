Brand packs

Give the console and the documentation an install's own colours, fonts, mark and name with a brand pack, which each viewer turns on when they want it.

For platform operators

The console and the documentation look the same everywhere unless an install sets a brand pack: their own look is called Ice line. A pack is a folder on the server that nuna.ui.brand.dir names; with Helm, a ConfigMap that brandConfigMap.name names. The pack changes how things look, never what a page shows or who may see it.

How a pack is served

Every console and documentation page links a brand stylesheet at a fixed path, /ui/brand/brand.css and /docs/assets/brand/brand.css, which always exists. The server's own is empty. With a pack set, the server serves the pack's files at both paths instead, and any file the pack lacks falls back to the server's own, so nothing answers 404. The page reads the pack before it first paints, so the pack shows from the start, with no flash of Ice line, and the Content-Security-Policy is the same with or without one. A documentation page opened from disk links the empty file and stays Ice line.

Each pack file is read afresh on every request, so a changed file reaches the next page loaded without a restart. The words in nuna.ui.brand.* are read at start-up.

What a pack holds

The files of a brand pack, all in one folder
FileNeededWhat it does
brand.cssyesThe pack's tokens and @font-face rules, below. It must set --brand-pack, or the page treats the folder as no pack.
favicon.svgnoThe browser tab's icon while the pack is on. Without it, the tab keeps Ice line's.
mark.svgnoThe mark in the console's header, on its sign-in page and in the documentation's header, in place of the peak; brand.css sets --brand-mark to say it is there. It is drawn in a fixed box at most 20 px high and 120 px wide, never squashed or cropped, so draw it at that ratio or narrower.
fontsnoThe font files brand.css names, as woff2, woff, ttf or otf, by URLs relative to brand.css.

File names are lower case letters, digits and hyphens. A Helm ConfigMap holds 1 MiB, enough for a couple of woff2 fonts.

The tokens a pack sets

A pack sets custom properties on :root and @font-face rules, nothing else: no rules aimed at the console's own classes, which change from release to release. Every token has Ice line's value until the pack sets it.

The brand pack's tokens
TokenWhat it sets
--brand-packRequired, any value, such as 1: says the file is a pack.
--brand-light-onlySet it for a pack with no dark colours: while the pack is on, the console and the documentation stay light and both theme switches go.
--brand-markSet it when the pack holds mark.svg.
--brand-mark-w, --mark-hThe mark's box: its width (at most 120px) and height (at most 20px).
--f-ui, --f-monoThe fonts for words and for names and code, each a font list ending in a system font.
--bg, --surface, --surface-2, --line, --line-strong, --sky, --text, --text-2The page, panels, fields, lines and text.
--accent, --accent-wash, --accent-mark, --on-accentLinks and primary buttons, the selected wash, chart marks and the text on an accent button.
--ok-*, --warn-*, --bad-*, --held-*, --frozen-*Each status's -ink, -wash and -mark: all is well, a warning, an error, a hold and a freeze.
--head-bg, --head-ink, --head-ink-2, --head-fieldThe console's header band, its ink, its quieter ink and its Go to a path field.
--rail-current-bg, --rail-current-inkThe current page in the console's menu.
--requested-bg, --requested-inkThe pill of a maintenance job someone requested, the one status drawn in the accent colour.

Body text must keep a contrast of at least 4.5:1 against its background, as Ice line's does. A pack with dark colours too sets them under both of Ice line's dark selectors, :root[data-theme="dark"] and, inside @media (prefers-color-scheme: dark), :root:not([data-theme="light"]), and leaves out --brand-light-only.

Turning a pack on and off

With a pack set, the console's header has a button beside the theme switch, its words from nuna.ui.brand.toggle-label; on a phone it is in the menu. A pack starts off for every viewer: the console and the documentation are Ice line until the viewer presses the button, which turns the pack on for that viewer, in that browser, and keeps it on across reloads. Pressing it again turns the pack off: Ice line's colours, fonts, peak, icon and the name nuna come back, and the theme switch returns. The documentation served beside the console follows the same choice. With no pack set there is no button.
