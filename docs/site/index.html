nuna documentation

nuna is an Apache Iceberg REST catalog built for a brokerage. It keeps every table's pointer in your own database, vends short-lived storage credentials to engines, records every change in a hash-chained audit trail, and maintains your tables overnight.

  • Iceberg REST, for any engine that speaks it
  • PostgreSQL, CockroachDB, Oracle or MongoDB
  • Branches and tags of a whole catalog
  • Grants, holds and row and column rules
