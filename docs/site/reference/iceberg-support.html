Iceberg support

Which Iceberg table format versions, REST catalog endpoints and access-delegation modes nuna serves, and which it does not.

Versions

WhatVersion
The REST catalog standard servedApache Iceberg 1.12.0's rest-catalog-open-api.yaml
The Iceberg library the server usesiceberg-core 1.12.0
Table format versions acceptedUp to 3. A create or commit that asks for a higher one is refused: Table format version n is not supported; the highest is 3.
Format version of a new table3, unless the request sets the format-version property.

The engine matrix tests format versions 2 and 3, and upgrading a table from 2 to 3 (Engine compatibility). Format version 1 is not tested.

REST endpoints

Every route of the standard, and whether nuna serves it. A served route is listed in GET /v1/config's endpoints for the prefixes that allow it (The prefix). A route not served answers 404 (NotFoundException).

Access delegation

X-Iceberg-Access-DelegationWhat nuna does
vended-credentialsAnswers short-lived S3 credentials for the table's location with each load and create, and refreshes them through the credentials route.
remote-signingNot served: the answer carries vended credentials.
none, aloneAnswers no credentials. This value is newer than the 1.12.0 standard.
No headerVends credentials, as for vended-credentials.
