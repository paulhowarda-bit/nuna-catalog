Limits

Every limit nuna enforces, its value, the setting that changes it and what happens when it is reached.

Every limit the server and its two companion programs enforce, with the setting that changes it where there is one. A limit with no setting is fixed in the code. A page size that is over its maximum is cut to the maximum unless the row says the request is refused.
