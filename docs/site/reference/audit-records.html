Audit record format

Every field of an audit record: the CloudEvents envelope, the shared parts, each record type's data, and the columns of the audit table.

Envelope

Each audit record is a CloudEvents 1.0 event in JSON, with its fields in this order.

FieldValue
specversion"1.0".
idThe record's id, a UUID.
sourceThe deployment: nuna.rest.audit-source, default urn:nuna:deployment:nuna-catalog.
typenuna.catalog.name, such as nuna.catalog.grant.
datacontenttype"application/json".
dataschemaurn:nuna:catalog:event:name:version, such as urn:nuna:catalog:event:grant:2.
subjectThe id of what the record is about, when it has one.
timeWhen it happened, an ISO-8601 instant.
partitionkeyThe same as subject, so records about one thing stay in order in the topic.
nunarun, nunaseqOn records written to the log: the log run, a UUID, and the record's number in the run, as a string. Together they place the record in its hash chain.
dataThe record type's fields, below.

Shared parts

Field names in data are in camel case, and enum values in upper case ("GRANTED", "TABLE").

PartFields
actorprincipal (who acted), endUser (the user a trusted engine acted for), engine, requestId (the X-Request-ID of the request).
securablekind (CATALOG, NAMESPACE, TABLE or VIEW), id, catalog (its name), path (namespace levels and name).
pointer statemetadataLocation, version, sha256 of the metadata file.

Record types

Each type, in the order the code defines them, with its current version and the fields of its data. Securables are named object, securable, target or table as each record has it.

TypeVersionData fields
nuna.catalog.commit1commitId, object, branch, before and after (pointer states), updates (the commit's updates, as a JSON array), actor.
nuna.catalog.grant2action (GRANTED or REVOKED), securable, group, privilege, actor, branch, branchId. A version 1 record has no branch or branchId; version 2 writes them as version 1 when both are null.
nuna.catalog.drop1object, purgeAfter, actor.
nuna.catalog.break-glass1securable, justification, actor.
nuna.catalog.read1object, branch, served (pointer state), actor.
nuna.catalog.denial1operation, securable (may be null), privilege (may be null), reason (code: message), actor.
nuna.catalog.auth-failure1issuer, claimedSubject, clientId, reason, requestId, remoteAddress. No subject.
nuna.catalog.credential-issue2object, storageProfile, locationPrefix, access (READ, READ_WRITE or READ_WRITE_DELETE), sessionName, expiresAt, actor, writePrefix.
nuna.catalog.namespace1action (CREATED, PROPERTIES_CHANGED or DROPPED), namespace, set, removed, actor.
nuna.catalog.rename1object, fromPath, actor.
nuna.catalog.engine1action (REGISTERED or REMOVED), issuer, clientId, endUserClaim, flags, actor. No subject.
nuna.catalog.storage-setup1action (PROFILE_SET or CATALOG_CREATED), id, name, settings, actor.
nuna.catalog.governance1action (SET or REMOVED), target, attribute, value, provenance, actor. A maintenance request is recorded with the attribute maintenance-request.
nuna.catalog.hold1action (PLACED or RELEASED), holdId, target, reason, actor.
nuna.catalog.undrop1object, actor.
nuna.catalog.purge1object, actor.
nuna.catalog.audit-read1target, returned (records returned), actor.
nuna.catalog.unregister1object, pointer, actor.
nuna.catalog.label1target, label, value, actor.
nuna.catalog.purge-claim1object, actor.
nuna.catalog.file-deletion1action (RECORDED or DELETED), object, files, notBefore, actor.
nuna.catalog.maintenance-exemption1object, operation, actor.
nuna.catalog.ref2action (CREATED, RENEWED, DELETED, MERGED, EXPIRING, EXPIRED or OBJECT_REMOVED), ref, name, kind (BRANCH or TAG), catalog, from, expiresAt, description (version 2, on CREATED only), tables, actor. The subject is the ref's id.
nuna.catalog.row-column-rule1action (SET or REMOVED), table, group, rowFilter, columnMasks, actor.
nuna.catalog.run-end1host. Closes a log run.

Audit table

The audit tables writer copies every record into an Iceberg table, by default nuna_audit.audit.events: format version 2, partitioned by day(time). The columns, by field id:

IdColumnTypeHolds
1event_idstring, requiredThe envelope's id.
2timetimestamptz, requiredThe envelope's time.
3typestring, requiredThe record type.
4sourcestring, requiredThe envelope's source.
5principalstringThe actor's principal. Empty for an auth failure.
6end_userstringThe actor's end user.
7enginestringThe actor's engine.
8request_idstringThe request id.
9catalogstringThe catalog's name.
10object_kindstringThe object's kind. A ref record's object is its catalog; a CATALOG_CREATED storage-setup record's is the new catalog.
11object_idstringThe object's id.
12object_pathlist of stringThe object's path.
13operationstringA denial's or maintenance exemption's operation.
14privilegestringA denial's or grant's privilege.
15reasonstringA denial's or hold's reason.
16datastring, requiredThe whole record, as JSON.
17topic_partitionint, requiredThe topic partition; -1 for a row read from the log.
18topic_offsetlong, requiredThe offset in that partition.
20log_runstringThe envelope's nunarun.
21log_seqlongThe envelope's nunaseq.
22branchstringThe branch or tag acted through.
23subject_idslist of stringThe ids the record is about, which the feed's subject filter matches.

Not documented yet: why field id 19 is unused. EventsTable.java skips it without saying.
