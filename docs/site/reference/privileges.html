Privileges

Each of the seven privileges: what it allows, on which objects it can be granted, what it includes, its words in the console, and every operation that needs it.

The privileges

In the order the code defines them. A privilege is written in lower case with hyphens, as the APIs take it. Any other name is refused with 400: unknown privilege 'name'; known: [describe, select, write, modify, create, manage-grants, manage-tags].

manage-tagsSetting governance attributes (classification, owner, retention class, the regulated and row-column-policy flags) and placing and releasing legal holds.catalog, namespace, table, viewdescribetagsSet labels and holds

A grant on a catalog or namespace reaches everything under it. Nothing includes create, manage-grants or manage-tags. The server refuses create on a table or view (create means nothing on a table: it creates namespaces, tables and views in a catalog or namespace) and write on a view (write means nothing on a view: it has no rows; select reads it, and modify changes its definition). A grant that names a catalog branch can only be write or modify. Which duties may share a group is in Authorization.
