Get started

Start with nuna: run the local demo on your laptop, connect an engine to a nuna that is already running, or install nuna on your own cluster.

There are three ways in. To try nuna, run the local demo: you need a Windows machine with Git Bash, Podman Desktop, kind, kubectl, helm, JDK 25 and a checkout of the repository, and the tutorials below walk you through it (The local demo says what it runs). To use a nuna that someone already runs, you need its address, a token from its identity provider and a grant on a catalog; start at Command line and clients. To run nuna for others, you need a Kubernetes cluster with Helm, a database, an object store and an identity provider; start at Install. The tutorials run on the demo, in this order.

  • Run nuna on your laptop Start the demo, sign in to the console as presenter, look at one table and stop the demo again.
  • Create your first table Get a token, create a namespace and a table, write rows from an engine, read them back and find the table's history in the console.
  • Tour the console Visit every page of the console once, with the demo's data.
  • Work on a catalog branch Write to the demo's branch dev, compare it with main, merge it and tag the result.
