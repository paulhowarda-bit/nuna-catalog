Module map

Each Gradle module of the nuna build and what it holds, in the order settings.gradle.kts lists them.

Modules

ModuleHolds
catalog-tests-s3Test support: the one S3 store every test uses, chosen with -Ps3=silo, ceph or aws, and the tests' Kafka broker.
catalog-tests-dockerTest support: the Testcontainers Docker client made safe for Podman, added to every test run.
catalog-coreDomain types, the commit loop, idempotency, the commit rules and authorization decisions.
catalog-icebergThe only module of nuna's own that imports iceberg-core: metadata parsing, applying updates and requirements, and the wire format.
catalog-store-apiThe storage interface every database implements, and the shared suite each must pass.
catalog-store-sqlThe PostgreSQL and CockroachDB store.
catalog-store-sql-raftTests only: the SQL store's suite on a CockroachDB cluster. Nothing depends on it.
catalog-store-oracleThe Oracle store.
catalog-store-mongoThe MongoDB store.
catalog-objectstoreStorage profiles, metadata file reading and writing with hash checks, and location guardrails.
catalog-securityToken validation, principals and trusted engines.
catalog-auditAudit events, the outbox relay, Kafka publishing, the change stream and the hash-chained archive.
catalog-serverThe Spring Boot server: the REST and management routes, settings, error mapping, self-checks, and the console under src/main/resources/nuna/ui/.
catalog-tests-loadLoad, contention, resilience and latency runs against running servers. Every test is tagged overnight.
catalog-tests-conformanceRuns the Iceberg REST Compatibility Kit against the server, with a record of which tests pass so none regresses.
catalog-tests-enginesThe engine matrix: Spark, Kafka Connect, PyIceberg and SingleStore against the server deployed by its Helm chart in a kind cluster.
singlestore-change-feedA SingleStore pipeline connector that reads a table's change feed and commits it to an Iceberg table through the catalog.
catalog-maintenanceThe maintenance worker, a separate service.
catalog-audit-tablesThe audit tables writer, a separate service.
demo-datagenThe demo's data generator, which produces the brokerage world.
