Guides

One task per guide, each from the console and the command line: data, access, governance, maintenance and audit.

Data

  • Create a catalog Declare a catalog with its storage profile, roll the servers and grant its first groups access.
  • Write, audit and publish with a branch Write to a catalog branch, check what changed, then merge it into main in one transaction or delete it.
  • Keep a point in time with a tag Make a read-only tag of the whole catalog, read through it, and remove it.
  • Read an earlier version of a table Read a snapshot, a time or a table ref from each engine, and find it on the History tab.
  • Register an existing table Bring a table's existing metadata file under nuna.
  • Rename or move a table or view Rename within a namespace or move to another, and what changes with it.
  • Change a table's settings Set a table's properties from the console's Settings drawer or from an engine.
  • Commit to several tables at once Commit changes to several tables in one transaction that lands whole or not at all.

Access

  • Grant and revoke access Give a group a privilege on a catalog, namespace, table or view, and take it back.
  • Add a row filter or column mask Flag a table, add a rule per group, and check what a reader sees.

Governance

  • Place and lift a legal hold Stop anything being removed from a table, namespace or catalog, and release it.
  • Freeze and unfreeze for disaster recovery Freeze writes to a table or catalog while a reconcile runs.
  • Drop, restore and purge a table Drop a table, restore it inside the window, or purge it for good.

Maintenance

  • Compact a table or scan for orphans now Ask the maintenance worker for one job on one table at its next scan.
  • Set a catalog's maintenance policy Choose what the worker does on its own: snapshot expiry, orphan removal, compaction and manifest rewrite.

Audit

  • Query the audit trail Find who did what and when, from the console, the audit feed or SQL on the audit table.
  • Verify the audit chain Check that a record holds its place in the hash chain and was archived unchanged.
