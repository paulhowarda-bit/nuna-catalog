Worker endpoints

The endpoints only the maintenance worker calls: its work list, file deletions, job, scan and assessment reports, DR verification work and branch expiry, under /management/v1/maintenance and each catalog's objects.

Internal Needs a maintenance principal

You never call these yourself: the worker does, as described in Maintenance. They are documented so you can read the worker's traffic and its refusals. Every route here needs a maintenance principal acting as itself; anyone else is refused with 403, only a maintenance principal may call operation, audited with the reason not_maintenance. The worker's storage prefixes are on Maintenance.

Work and deletions

GET /management/v1/maintenance/work

Gives the worker its work list, one section at a time, paged with pageToken and pageSize.

Internal Needs a maintenance principal

Parameters

NameInTypeRequiredDescription
sectionquerystringNotables, purges, deletions, requests or refs.
pageToken, pageSizequeryNoPaging within the section.

Responses

StatusWhen
200{"tables", "purges", "deletions", "refs", "requests", "next-page-token"}.
400No work list section x; there are tables, purges, deletions, requests and refs, or The page token is not one of section x.
403The caller is not a maintenance principal.

Not documented yet: the fields of each work list item. This page was written from the route's checks, not from the item builders.

POST /management/v1/catalogs/{catalog}/objects/{id}/pending-deletions

Records files of a table that the worker will delete once the cleanup window allows. Every location must lie beneath the table's location.

Internal Needs a maintenance principal Audited

Parameters

NameInTypeRequiredDescription
locationsbodyarray of stringsYes1 to 1000 file locations.
refsbodyarray of stringsYesThe ids of the refs the worker found naming the table.

Responses

StatusWhen
201 or 200{"recorded", "not-before"}.
400Field locations must be an array of 1 to 1000 items, or Every location must lie beneath the table's location r, with no empty, . or .. segment, not x.
409The refs naming the table changed (RefsChangedException, with the current refs), or the table is not active or dropped: id is state: only an active or dropped table's files are recorded for deletion (NotDeletableException).

POST /management/v1/catalogs/{catalog}/objects/{id}/pending-deletions/complete

Marks recorded deletions done, by their ids: {"ids": […]}.

Internal Needs a maintenance principal Audited

Responses

StatusWhen
204The deletions are marked done.

Reports

PUT /management/v1/maintenance/jobs/{id}

Reports one job, at its start and again at its end, for the nights. The report itself is not audited; a refusal is.

Internal Needs a maintenance principal

Request body

night, opens, closes, kind (compaction, orphan-scan, snapshot-expiry, manifest-rewrite, purge, deletion), object-id, slot, started-at, ended-at, outcome (running, succeeded, failed, cut-off), files-in, files-out, snapshots-expired, files-deleted, bytes-deleted and, for a requested job, requested-at.

Responses

StatusWhen
204The job is recorded.
404The catalog never had the object.

PUT /management/v1/maintenance/scans/{id}

Reports a scan, at its start and at its end, with what the worker reached on each store. The scans and readiness read these reports.

Internal Needs a maintenance principal

Request body

started-at, and optionally ended-at, outcome, failures, error and storage.

Responses

StatusWhen
204The scan is recorded.

PUT /management/v1/maintenance/tables/{id}/assessment

Reports a table's assessment, which table health shows.

Internal Needs a maintenance principal

Request body

catalog, namespace, name, assessed-at, data-files, small-files, position-delete-files, deletion-vectors, equality-delete-files, reasons and score.

Responses

StatusWhen
204The assessment is recorded.
404The table is not there.
409The id now names another table (TableReplacedException).

PUT /management/v1/maintenance/tables/{id}/compaction

DR verification

GET /management/v1/maintenance/dr-work

Gives the DR verifier every active table and view whose DR watermark is below its main pointer, or which has none, by id: each with its location, its pointer, its watermark, the journaled versions above the watermark, oldest first, and when the oldest of them was committed. See Disaster recovery.

Internal Needs a maintenance principal

Parameters

NameInTypeRequiredDescription
pageTokenquerystringNoThe next-page-token of the page before.
pageSizequeryintegerNoDefault 100, at most 1000.

Responses

StatusWhen
200The work list, with next-page-token while more follows.
400Invalid page token: x.

PUT /management/v1/maintenance/tables/{id}/dr-watermark

Records that the verifier found every file of a version of the object's main pointer in the DR store: {"version": n, "metadata-location": "…"}. The location must be the one the journal records for that version, or the pointer's. A watermark never moves back.

Internal Needs a maintenance principal

Responses

StatusWhen
204The watermark is recorded, or that version was kept already.
400Not a table or view id: x, or Missing field version: a pointer version, from 1.
404No active table or view id (NoSuchTableException).
409A higher DR watermark is kept for id than version n, and a watermark never moves back (WatermarkBehindException); the version is above the pointer (WatermarkAheadException); The journal holds no version n of id (UnknownVersionException); or Version n of id is location, not other (WatermarkMismatchException).

Ref expiry

A catalog branch expires when it has not been renewed (see renewing a branch). The worker warns within nuna.refs.expiry-warning of the expiry and ends the branch once it has passed; each leaves a ref record (EXPIRING, EXPIRED).

POST /management/v1/maintenance/refs/{id}/warn

Records the warning that a branch is about to expire.

Internal Needs a maintenance principal Audited

Responses

StatusWhen
200{"id", "expires-at", "sent"}.
409Ref name is not within d of an expiry (nuna.refs.expiry-warning) (RefNotExpiringException), or a warning for it is already being sent (RefWarningInFlightException).

POST /management/v1/maintenance/refs/{id}/end

Ends a branch past its expiry, freeing its name.

Internal Needs a maintenance principal Audited

Responses

StatusWhen
204The branch is ended.
400Not a ref id: x.
409Ref name is a tag, which never expires, or Ref name expires at time (RefNotExpiredException).
