Iceberg REST: views

List, create, load, replace, rename, register and drop views, under /v1/{prefix}/namespaces/{namespace}/views.

A view is a stored query that engines expand when they read it. These are the standard's view endpoints; this page gives what nuna does differently. Views share their names with tables in a namespace, matched without regard to case. The catalog assigns each view's location, as it does a table's. Every write takes an Idempotency-Key and is audited. Through a branch, replacing a view changes only the branch's version; through a tag, only reads are served (The prefix). The examples use curl with NUNA and TOKEN set as Use the APIs with curl describes.

Loading a view gives no storage credentials and no ETag: a view has no data files.

GET /v1/{prefix}/namespaces/{namespace}/views

Lists the views in a namespace, with the same parameters and paging as listing tables.

Needs describe on the namespace

Responses

StatusWhen
200{"identifiers": [{"namespace": […], "name": "…"}, …], "next-page-token": token or null}.
404Namespace does not exist: namespace.

Example

curl -sS "$NUNA/v1/trading/namespaces/equities/views" -H "Authorization: Bearer $TOKEN"
{"identifiers": [{"namespace": ["equities"], "name": "open_orders"}], "next-page-token": null}

POST /v1/{prefix}/namespaces/{namespace}/views

Creates a view from the standard's create-view request: name, schema, view-version and optional properties. A location in the request is not used: the catalog assigns one.

Needs create on the namespace Audited

Responses

StatusWhen
200The load view result of the new view.
400The request is not valid, for example Invalid view name: …; or the prefix names a branch or tag.
404Namespace does not exist: namespace.
409View already exists: …, or Table with same name already exists: … (AlreadyExistsException).

GET /v1/{prefix}/namespaces/{namespace}/views/{view}

Loads a view's metadata. Through a branch or tag, it is that ref's version. Each load is recorded as a read.

Needs select on the view Audited

Responses

StatusWhen
200The load view result.
403You hold something on the view but not select.
404View does not exist: namespace.view (NoSuchViewException), also when you hold nothing on it.

Example

curl -sS "$NUNA/v1/trading/namespaces/equities/views/open_orders" -H "Authorization: Bearer $TOKEN"

HEAD /v1/{prefix}/namespaces/{namespace}/views/{view}

Says whether a view exists, with no body. A view you hold nothing on answers as missing.

Needs describe on the view

Responses

StatusWhen
204It exists.
404It does not exist, or you may not see it.

POST /v1/{prefix}/namespaces/{namespace}/views/{view}

Replaces a view: the standard's commit-view request, with requirements and updates, usually adding a new version and making it current. On main, replacing a view that does not exist creates it, and needs create on the namespace. Through a branch, it changes the branch's version of a view the branch holds.

Needs modify on the view Audited

Responses

StatusWhen
200The load view result after the change.
400The request is not valid, or the prefix names a tag.
403You lack modify.
404View does not exist: …; through a branch, also for a view the branch does not hold.
409A requirement failed (CommitFailedException): load the view again and redo the change.

DELETE /v1/{prefix}/namespaces/{namespace}/views/{view}

Drops a view. As with tables, the drop is soft: the view can be restored until it is purged, nuna.rest.drop-retention after the drop.

Needs modify on the view Audited

Responses

StatusWhen
204Dropped.
400The prefix names a branch or tag.
403You lack modify, or the view is under a legal hold.
404View does not exist: ….

POST /v1/{prefix}/views/rename

Renames a view, or moves it to another namespace of the same catalog, with the same body as renaming a table.

Needs modify on the view and create on the target namespace Audited

Responses

StatusWhen
204Renamed.
400Invalid rename: source and destination are required, or the prefix names a branch or tag.
404The view or the target namespace does not exist.
409Cannot rename source to destination. View already exists, or … Table already exists.

POST /v1/{prefix}/namespaces/{namespace}/register-view

Registers a view whose metadata file already exists, at the location the catalog assigns for its UUID. The file a dropped or unregistered view left behind brings that view back, in the namespace it left. The body is {"name": "…", "metadata-location": "…"}.

Needs create on the namespace Audited

Responses

StatusWhen
200The load view result.
400The file is not at the location the catalog assigns, or the prefix names a branch or tag.
404The namespace or the metadata file does not exist.
409The name is taken, or another table or view holds the file's UUID (AlreadyExistsException); or the dropped view's restore window has closed (UndropWindowClosedException).

Objects

Load view result

FieldTypeDescription
metadata-locationstringThe view's current metadata file.
metadataobjectThe view metadata, as the Iceberg view spec defines it.
labelsobjectOnly when set: {"object-labels": {"classification", "owner", "retention-class"}}, from the view's governance attributes.

The answer has no config: nuna sends no client settings with a view.
