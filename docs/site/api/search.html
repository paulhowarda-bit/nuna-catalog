Name search and listings

Find namespaces, tables and views by part of their name across every catalog, and list a namespace's tables and child namespaces with their figures, under /management/v1.

The console uses these reads for Go to a path and for the Contents of a catalog or namespace. Each lists only what the caller may see and skips the rest without naming or counting it, so a listing never refuses an object and writes no audit record for one. None of them loads a table or reads its data. The examples use curl with $NUNA and $TOKEN set as curl shows.

The {namespace} segment joins its levels with the unit separator, %1F in a URL: equities%1Fdaily. A caller who holds nothing in a catalog it names gets 404 NoSuchWarehouseException (The given warehouse does not exist: trading), and the refusal is audited.

Endpoints

MethodPathWhat it does

GET /management/v1/names

Finds every namespace, table and view whose name holds the fragment q, ignoring case, in every catalog the caller holds something in, or in one catalog. A name is matched alone, not as a path: q=order finds equities.orders but q=equities.orders finds nothing.

The search lists:

  • a catalog only where the caller holds a grant on it or on anything in it, as the catalog list counts it;
  • a namespace only where one of the caller's grants is on it, above it or on something in it;
  • a table or view only where the caller may describe it.

Namespaces come first, all on the first page, catalog by catalog in name order. Then come tables, then views, across catalogs. A page looks at 5000 objects at most, and ends early with a token when it has not found enough; keep reading while next-page-token is there. Namespaces after the first page's are never returned: when the first page could not hold every matching namespace, or the walk stopped at its limit, the answer says "more-namespaces": true, and a longer fragment narrows the search.

Needs describe on each object listed

Parameters

NameInTypeRequiredDescription
qquerystringYesPart of a name. Spaces around it are dropped.
catalogquerystringNoSearch one catalog only. It must be a catalog in nuna.storage.catalogs that the caller holds something in.
pageTokenquerystringNoThe next-page-token of the page before.
pageSizequeryintegerNoRows in one page. Default 50; a value outside 1 to 200 is taken as the nearer bound.

Responses

StatusWhen
200{"names": [name, …], "more-namespaces", "next-page-token"}, each name as in Name. A caller who holds nothing in any catalog gets {"names": []} at once.
400Give part of a name to search for, Required parameter 'q' is not present., or Invalid page token: ….
404catalog names a catalog the server does not declare, or one you hold nothing in (NoSuchWarehouseException). Only the second is audited.

Example

curl -sS "$NUNA/management/v1/names?q=order" -H "Authorization: Bearer $TOKEN"
{
  "names": [
    {"catalog": "trading", "kind": "table", "namespace": ["equities"], "name": "orders"},
    {"catalog": "trading", "kind": "view", "namespace": ["equities"], "name": "open_orders"}
  ]
}

A fragment that matches more namespaces than one page holds ends the first page with them:

{
  "names": [
    {"catalog": "trading", "kind": "namespace", "namespace": [], "name": "equities"},
    {"catalog": "trading", "kind": "namespace", "namespace": [], "name": "reference"}
  ],
  "more-namespaces": true,
  "next-page-token": "AAAAAXQAAAAAAAAAATA"
}

GET /management/v1/catalogs/{catalog}/namespaces/{namespace}/tables

Lists the active tables directly in the namespace, by name, each with its format version, its number of snapshots and its last commit. Views and dropped tables are not listed. The figures come from what the server stores beside each table's pointer and from the commit journal: no metadata file is read, no table is loaded, and nothing is audited per table.

A table is listed only to a caller who may describe it. A page holds fewer rows than pageSize, even none, when the caller may describe few of the tables it looks at (1000 at most), so keep reading while next-page-token is there.

Through ref, the list is the namespace and tables of that catalog branch or tag's cut, by the names the cut has, and each table as the ref reads it. Rights are main's: a table is listed to a caller who may describe it on main.

Needs a grant on the namespace, above it or in it

Parameters

pageTokenquerystringNoThe next-page-token of the page before.
pageSizequeryintegerNoRows in one page. Default 100; a value outside 1 to 200 is taken as the nearer bound.

GET /management/v1/catalogs/{catalog}/namespaces

Lists the catalog's top namespaces, by name, each with totals over every table beneath it, at every depth, that the caller may describe: how many, their snapshots summed, and the newest commit among them. A namespace the caller holds nothing on, above or in is not a row, so its name is not given. Views and dropped tables are not counted. Any caller who holds something in the catalog is answered.

A page looks at 1000 tables and namespaces at most. A namespace whose walk would pass that waits for the next page, so its totals are whole there, unless it is the page's first row: then its totals cover what it looked at and say "complete": false.

Through ref, the namespaces and tables are the cut's, each table counted as the ref reads it, and the walk goes down only into namespaces the caller holds something on, above or in.

Needs a grant in the catalog

Parameters

NameInTypeRequiredDescription
catalogpathstringYesThe catalog's name.
pageTokenquerystringNoThe next-page-token of the page before.
pageSizequeryintegerNoRows in one page. Default 100; a value outside 1 to 200 is taken as the nearer bound.
refquerystringNoA catalog branch or tag to list through.

Responses

StatusWhen
200{"namespaces": [namespace row, …], "next-page-token"}, each row as in Namespace row.
400Invalid page token: ….
404You hold nothing in the catalog, or it does not exist (NoSuchWarehouseException). Ref does not exist: ref (NoSuchRefException).

Example

GET /management/v1/catalogs/{catalog}/namespaces/{namespace}/namespaces

Lists a namespace's child namespaces with the same totals, paging and ref as the catalog's top namespaces. The parent namespace is answered to a caller who holds something on it, above it or in it.

Needs a grant on the namespace, above it or in it

Objects

Name

FieldTypeDescription
catalogstringThe catalog's name, as the server's settings declare it.
kindstringnamespace, table or view.
namespacearray of stringsThe levels above the name, outermost first; empty for a top namespace.
namestringThe matching name.

Table row

FieldTypeDescription
idstringThe table's id.
namestringThe table's name; through a ref, the name the cut has.
format-versionintegerThe Iceberg format version of the metadata the pointer names.
snapshotsintegerThe number of snapshots in that metadata.
refobjectThrough a ref only. pointer is own for a branch's own pointer, which its commits made, or cut for the pointer its cut took. version is that pointer's version, numbered on line: the ref's own name for its own pointer, or main, or the ref the cut took a branch's own pointer from. line is left out when the journal that wrote the pointer cannot be found.
last-commitobjectThe journal's entry that wrote the pointer: version, line (through a ref), committed-at, principal, and end-user and engine when there were any. Left out when the entry cannot be found.

Through a ref, a cut's pointer keeps no stored figures. While main's pointer is still the cut's file, main's figures serve; otherwise the server reads the cut's metadata file, checked against the SHA-256 the cut kept. A file that no longer matches gives no format-version or snapshots, and raises the metadata integrity alert.

Namespace row

FieldTypeDescription
namestringThe child namespace's name.
tablesintegerActive tables beneath it, at every depth, that the caller may describe.
snapshotsintegerTheir snapshots, summed.
completebooleanfalse when the page's limit cut the walk short and the totals cover only what it looked at.
newest-commitobjectThe latest commit among those tables: as last-commit in a table row, with table, the table's levels below the child namespace. Left out when no table is counted.
