Governance

Read a catalog's governance summary, set governance attributes, place and release legal holds, and freeze objects for DR, under /management/v1/catalogs/{catalog}.

Attributes, holds and freezes sit on a catalog, a namespace, a table or a view, and the routes for them are served on each of the four paths. On this page, object stands for one of /management/v1/catalogs/{catalog}, …/namespaces/{namespace}, …/namespaces/{namespace}/tables/{table} and …/namespaces/{namespace}/views/{view}. The {namespace} segment joins its levels with the unit separator, %1F in a URL: equities%1Fdaily. See Governance for what each attribute, hold and freeze does. The examples use curl with $NUNA and $TOKEN set as curl shows.

Every refusal is audited. A caller who holds nothing on the object is answered with its not-found error: NoSuchWarehouseException, NoSuchNamespaceException (Namespace does not exist: equities.daily), NoSuchTableException or NoSuchViewException.

Reading governance

GET /management/v1/catalogs/{catalog}/governance/summary

Counts the catalog's tables by their governance, and lists where the catalog is regulated, closed and flagged. A read writes no audit record.

Needs describe on the catalog

Responses

StatusWhen
200The governance summary follows.
403You hold something in the catalog but not describe on it.
404You hold nothing in the catalog, or it does not exist.

Example

curl -sS "$NUNA/management/v1/catalogs/trading/governance/summary" -H "Authorization: Bearer $TOKEN"

  "freezes": 1,

      "closed": 1,
      "provenance": "MiFID II record keeping",
      "set-by": "kim",
      "set-at": "2026-11-20T10:04:00.120411Z"

GET /management/v1/catalogs/{catalog}/governance/dr-freezes

Lists the DR freezes standing anywhere in the catalog, the newest placed first, for the platform operators who may lift them: each with what it is on, its reason as recorded, who placed it and when. It lists no legal hold, no freeze lifted before, and nothing about the tables beneath a frozen level. Anyone else who holds a grant in the catalog reads freezes with the holds, on …/governance/holds, which an operator is refused. A refusal is audited; a read writes no audit record.

Needs a platform operator

Responses

StatusWhen
200{"catalog", "freezes": [{"on", "reason", "placed-by", "placed-at"}, …]}.
403You hold something in the catalog but are not a platform operator.
404You hold nothing in the catalog, or it does not exist.

Example

curl -sS "$NUNA/management/v1/catalogs/trading/governance/dr-freezes" -H "Authorization: Bearer $TOKEN"
{
  "catalog": "trading",
  "freezes": [
    {
      "on": {"kind": "namespace", "id": "4b5c6d7e-8f90-4a1b-9c2d-3e4f5a6b7c8d", "path": ["reference"]},
      "reason": "reconcile after failover",
      "placed-by": "ops-lee",
      "placed-at": "2026-11-25T08:00:12.551Z"
    }
  ]
}

GET /management/v1/catalogs/{catalog}/governance

Also served on the namespace, table and view paths. Reads the attributes set on the object and on every level above it, the value of each attribute that applies to the object (effective), and the holds on it and above it. The row-column-policy flag is not inherited: only a table's own flag counts, so it does not appear in effective from a level above. On a table, a caller who holds manage-tags or manage-grants also gets how many row and column rules it has, and for which groups.

Needs describe on the object

Responses

StatusWhen
200The object's governance follows.
400The namespace segment has an empty level: Invalid namespace: ….
403You hold something on the object but not describe.
404The object is not there, or you hold nothing on it.

Example

curl -sS "$NUNA/management/v1/catalogs/trading/namespaces/equities/tables/fills/governance" \
  -H "Authorization: Bearer $TOKEN"
{
  "target": {"kind": "table", "id": "7a8b9c0d-1e2f-4a3b-8c4d-5e6f7a8b9c0d"},
  "attributes": [
    {
      "attribute": "regulated",
      "level": "namespace:2c4e6a80-1b3d-4f5a-8c7e-9a0b1c2d3e4f",
      "value": "true",
      "provenance": "MiFID II record keeping",
      "set-by": "kim",
      "set-at": "2026-11-20T10:04:00.120411Z"
    }
  ],
  "effective": {"regulated": "true"},
  "holds": [
    {
      "id": "c1d2e3f4-a5b6-4c7d-8e9f-0a1b2c3d4e5f",
      "level": "table:7a8b9c0d-1e2f-4a3b-8c4d-5e6f7a8b9c0d",
      "reason": "case 2026-114",
      "placed-by": "kim",
      "placed-at": "2026-11-24T16:40:03.918Z"
    }
  ]
}

Attributes

PUT /management/v1/catalogs/{catalog}/attributes/{attribute}

Also served on the namespace, table and view paths. Sets one governance attribute on the object, with the value and where it comes from (provenance). The attributes are classification, owner, retention-class, regulated and row-column-policy. A value set on a catalog or namespace applies to everything beneath it, except row-column-policy, which goes on a table only.

Needs manage-tags on the object Audited

Parameters

NameInTypeRequiredDescription
attributepathstringYesOne of the five attributes.
valuebodystringYesThe value, at most 1000 characters. regulated and row-column-policy take true or false; retention-class takes a class named in nuna.governance.retention-classes.
provenancebodystringYesWhy, or on whose authority, at most 1000 characters.

Request body

{"value": "true", "provenance": "MiFID II record keeping"}

Responses

StatusWhen
200The attribute is set; the answer is the attribute as in attributes of the object's governance.
400
  • Missing field value: a non-empty string, Field provenance is longer than 1000 characters
  • Unknown retention class x; configured classes: […]
  • regulated is true or false, not x
  • The row-column-policy flag goes on a table, not on a kind: only a table's own flag is enforced, so set it on each table to protect
403You hold something on the object but not manage-tags.
404The attribute is unknown: Unknown governance attribute x; known attributes: [classification, owner, regulated, retention-class, row-column-policy] (NoSuchAttributeException). Or the object is not there, or went away: The kind no longer exists (NoSuchObjectException).
409Setting row-column-policy to false on a table that has rules: The table has row filters or column masks; the grant admin removes them before its row/column-policy flag can be removed or set false (RowColumnRulesExistException).

A change is audited as a governance record. A change to classification, owner or retention-class also leaves a label record.

Example

curl -sS -X PUT "$NUNA/management/v1/catalogs/trading/namespaces/equities/attributes/regulated" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"value": "true", "provenance": "MiFID II record keeping"}'

DELETE /management/v1/catalogs/{catalog}/attributes/{attribute}

Also served on the namespace, table and view paths. Removes an attribute set on the object itself. A value inherited from above stays.

Needs manage-tags on the object Audited

Responses

StatusWhen
204The attribute is removed.
403You hold something on the object but not manage-tags.
404attribute is not set on this kind (NoSuchAttributeException), an unknown attribute, or a missing object.
409Removing row-column-policy from a table that has rules (RowColumnRulesExistException).

Example

curl -sS -X DELETE "$NUNA/management/v1/catalogs/trading/namespaces/equities/attributes/owner" \
  -H "Authorization: Bearer $TOKEN"

Holds and freezes

A legal hold stops anything under it from being removed. A DR freeze refuses commits, creates, drops, renames, restores and purges under it, with the message what is frozen for DR reconcile: reason and the audit reason dr_freeze. A refusal for a hold has the audit reason legal_hold.

POST /management/v1/catalogs/{catalog}/holds

Also served on the namespace, table and view paths. Places a legal hold on the object. An object may carry several holds, each with its own id.

Needs manage-tags on the object Audited

Parameters

NameInTypeRequiredDescription
reasonbodystringYesWhy the hold is placed, such as a case number.

Responses

StatusWhen
201{"id", "level", "reason", "placed-by", "placed-at"}. Keep id to release the hold.
400Missing field reason: a non-empty string.
403You hold something on the object but not manage-tags.
404The object is not there, or you hold nothing on it.

Example

curl -sS -X POST "$NUNA/management/v1/catalogs/trading/namespaces/equities/tables/fills/holds" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reason": "case 2026-114"}'
{
  "id": "c1d2e3f4-a5b6-4c7d-8e9f-0a1b2c3d4e5f",
  "level": "table:7a8b9c0d-1e2f-4a3b-8c4d-5e6f7a8b9c0d",
  "reason": "case 2026-114",
  "placed-by": "kim",
  "placed-at": "2026-11-24T16:40:03.918Z"
}

DELETE /management/v1/catalogs/{catalog}/holds/{holdId}

Also served on the namespace, table and view paths. Releases a hold, on the path of the object it was placed on.

Needs manage-tags on the object Audited

Responses

StatusWhen
204The hold is released.
400Not an id: x.
403You hold something on the object but not manage-tags.
404No hold id on this kind (NoSuchHoldException), including a hold placed on another level.

Example

curl -sS -X DELETE "$NUNA/management/v1/catalogs/trading/namespaces/equities/tables/fills/holds/c1d2e3f4-a5b6-4c7d-8e9f-0a1b2c3d4e5f" \
  -H "Authorization: Bearer $TOKEN"

PUT /management/v1/catalogs/{catalog}/dr-freeze

Also served on the namespace, table and view paths. Freezes the object while DR reconcile runs. The freeze also turns off every maintenance job beneath it.

Needs a platform operator Audited

Parameters

NameInTypeRequiredDescription
reasonbodystringYesWhy, shown in every refusal the freeze causes.

Responses

StatusWhen
200The freeze is set; the answer is the dr-freeze attribute.
403You are not a platform operator: only platform operators may call setDrFreeze.
404The object is not there.

Example

curl -sS -X PUT "$NUNA/management/v1/catalogs/trading/namespaces/reference/dr-freeze" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reason": "reconcile after failover"}'

DELETE /management/v1/catalogs/{catalog}/dr-freeze

Also served on the namespace, table and view paths. Lifts the freeze.

Needs a platform operator Audited

Responses

StatusWhen
204The freeze is lifted.
403You are not a platform operator.
404The object is not there, or carries no freeze of its own: dr-freeze is not set on this kind.

Example

curl -sS -X DELETE "$NUNA/management/v1/catalogs/trading/namespaces/reference/dr-freeze" \
  -H "Authorization: Bearer $TOKEN"

Objects

Governance summary

FieldTypeDescription
catalogstringThe catalog's name.
tablesobjectCounts of tables: total, classified, closed, held, frozen and flagged.
holds, freezesintegerStanding holds and freezes in the catalog.
regulatedarrayEach place regulated is set: on ({"kind", "id", "path"}), tables and closed beneath it, provenance, set-by, set-at.
closedarrayEach closed object, as on.
flaggedarrayEach flagged table, as on, with its number of rules.

A table is closed while a level on or above it is regulated and it has no classification of its own, and the server's authorization treats it as closed until it is classified. A classification inherited from above labels the table but does not open it.

Hold or freeze

FieldTypeDescription
kindstringhold or freeze.
idstringA hold's id. Freezes have none: one object carries one freeze.
onobject{"kind", "id", "path"}.
reason, placed-by, placed-atstringWhy, who and when.
lifted-by, lifted-atstringIn lifted only: who lifted it, and when.

Object governance

FieldTypeDescription
targetobject{"kind", "id"} of the object asked about.
attributesarrayEach attribute set on the object or above it: attribute, level (kind:id of where it is set), value, provenance, set-by, set-at.
effectiveobjectAttribute name to the value that applies to the object.
holdsarrayEach hold on the object or above it: id, level, reason, placed-by, placed-at.
row-column-rulesobjectOn a table, for a caller with manage-tags or manage-grants: count and groups.
