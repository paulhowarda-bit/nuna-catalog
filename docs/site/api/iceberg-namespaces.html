Iceberg REST: namespaces

List, create, load, check, drop and change the properties of namespaces, under /v1/{prefix}/namespaces.

A namespace holds tables, views and other namespaces, to any depth (Catalogs, namespaces, tables and views). In a path, {namespace} is every level joined by %1F: equities%1Fdaily is equities.daily. In a body, a namespace is an array of its levels, ["equities", "daily"].

Names are unique without regard to case: Equities and equities are the same namespace. The server keeps and answers the name as it was first given. A level may not be empty.

Through a branch or tag prefix, namespaces can be listed, loaded and checked, and the properties answered are main's; creating, dropping and changing properties happen on main only (The prefix). The examples use curl with NUNA and TOKEN set as Use the APIs with curl describes.

Endpoints

Namespace endpoints
MethodPathWhat it does

GET /v1/{prefix}/namespaces

Lists the namespaces one level below parent, or the top-level namespaces when parent is missing, sorted by name. Paging works as Paging describes: without pageToken, every namespace comes in one answer.

Needs describe on the parent

Parameters

NameInTypeRequiredDescription
prefixpathstringYesThe catalog, or catalog@ref.
parentquerystringNoThe namespace to list under, levels joined by %1F.
pageTokenquerystringNoEmpty for the first page; then the last answer's next-page-token.
pageSizequeryintegerNoNamespaces per page, with pageToken only. Default 100, at most 1000.

Responses

StatusWhen
200{"namespaces": [[level, …], …], "next-page-token": token or null}.
400A bad page size or token: Invalid page size: 0, Invalid page token: ….
404The parent does not exist, or you hold nothing on it (NoSuchNamespaceException); or the catalog or ref does not exist (NoSuchWarehouseException).

Example

curl -sS "$NUNA/v1/trading/namespaces?parent=equities" -H "Authorization: Bearer $TOKEN"
{"namespaces": [["equities", "daily"]], "next-page-token": null}

POST /v1/{prefix}/namespaces

Creates a namespace, with properties if given. Its parent must already exist: create equities before equities.daily. The creation is audited. Takes an Idempotency-Key (Idempotency keys).

Needs create on the parent Audited

Body

NameInTypeRequiredDescription
namespacebodyarray of stringsYesThe new namespace's levels, its parent's first.
propertiesbodyobjectNoString keys and values. A key or value may not be null.

Responses

StatusWhen
200Created: {"namespace": […], "properties": {…}}.
400The body is not valid, for example Invalid namespace: empty; or the prefix names a branch or tag.
403You hold something on the parent, but not create.
404The parent does not exist: Namespace does not exist: parent (NoSuchNamespaceException).
409Namespace already exists: namespace (AlreadyExistsException), also when the name differs only in case.
500The database did not say whether the write was applied and reading it back did not settle it: Creating namespace … may or may not have been applied: … (ServiceFailureException). Repeat with the same Idempotency-Key.

Example

curl -sS -X POST "$NUNA/v1/trading/namespaces" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: create-equities-daily-1" \
  -d '{"namespace": ["equities", "daily"], "properties": {"owner": "trading-engineers"}}'
{"namespace": ["equities", "daily"], "properties": {"owner": "trading-engineers"}}

GET /v1/{prefix}/namespaces/{namespace}

Answers a namespace's levels and properties.

Needs describe on the namespace

Responses

StatusWhen
200{"namespace": […], "properties": {…}}.
404Namespace does not exist: namespace (NoSuchNamespaceException), also when you hold nothing on it.

Example

curl -sS "$NUNA/v1/trading/namespaces/equities%1Fdaily" -H "Authorization: Bearer $TOKEN"

HEAD /v1/{prefix}/namespaces/{namespace}

Says whether a namespace exists, with no body. A namespace you hold nothing on answers as missing.

Needs describe on the namespace

Responses

StatusWhen
204It exists.
404It does not exist, or you may not see it.

DELETE /v1/{prefix}/namespaces/{namespace}

Drops a namespace that holds nothing: no table, view or namespace, and no table or view that a branch or tag still names. The drop is audited. Takes an Idempotency-Key.

Needs modify on the namespace Audited

Responses

StatusWhen
204Dropped.
400The prefix names a branch or tag.
403You lack modify, or Namespace namespace is under a legal hold and cannot be dropped (ForbiddenException).
404Namespace does not exist: namespace (NoSuchNamespaceException).
409Namespace namespace is not empty, or Namespace namespace is not empty: a branch or tag names a table or view in it (NamespaceNotEmptyException).

Example

curl -sS -X DELETE "$NUNA/v1/trading/namespaces/equities%1Fdaily" -H "Authorization: Bearer $TOKEN"

POST /v1/{prefix}/namespaces/{namespace}/properties

Sets some properties and removes others, in one change that is audited. A key may not be in both lists. If the namespace changes while the update runs, the server tries again, up to five times, and then gives up with nothing applied. Takes an Idempotency-Key.

Needs modify on the namespace Audited

Body

NameInTypeRequiredDescription
updatesbodyobjectNoProperties to set.
removalsbodyarray of stringsNoKeys to remove.

Responses

StatusWhen
200{"updated": […], "removed": […], "missing": […]}: the keys set, the keys removed, and the keys asked to be removed that were not there.
400The prefix names a branch or tag, or the body is not valid.
404Namespace does not exist: namespace.
422Invalid namespace update, cannot simultaneously set and remove keys: […] (UnprocessableEntityException).
500Namespace namespace changed 5 times while its properties were updated; nothing was applied (ServiceFailureException). Send it again.

Example

curl -sS -X POST "$NUNA/v1/trading/namespaces/equities/properties" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"updates": {"owner": "trading-engineers"}, "removals": ["comment"]}'
{"updated": ["owner"], "removed": ["comment"], "missing": []}
