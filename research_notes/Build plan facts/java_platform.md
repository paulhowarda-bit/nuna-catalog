**Risks and possible blockers**

- **R1. Flyway has no current YugabyteDB module.** The only YugabyteDB module, `org.flywaydb:flyway-database-yugabytedb`, is at 10.26.2. It comes from the community repository, and its parent POM builds it against flyway-core **11.9.0**. Nothing has been published for 12.x or 13.x. I did not test whether it works with Flyway 12.4 or 13.12. This blocks Flyway on YugabyteDB until a spike proves it works.
- **R2. Jackson 2 version skew.** Boot 4.1.2 imports `com.fasterxml.jackson:jackson-bom` 2.21.7, and iceberg-core 1.12.0 declares jackson-core/databind 2.22.2. Maven dependency management will therefore downgrade iceberg's Jackson to 2.21.7. Overriding `jackson-2-bom.version` to 2.22.x has its own cost: Boot imports the Jackson 2 BOM before the Jackson 3 BOM, so the override also moves the shared `jackson-annotations` from 2.21 to 2.22. Jackson 3.1.7 declares annotations 2.21. Whichever way you choose, run a test before pinning.
- **R3. Jackson 2 support in Spring is being removed.** The Spring Framework 7.0 release notes say the current plan is to "disable [Jackson 2] auto-detection in 7.1 and remove its support entirely in 7.2". `MappingJackson2HttpMessageConverter` is `@Deprecated(since="7.0", forRemoval=true)`. Boot's Jackson 2 converter configuration is "deprecated since 4.0.0 for removal in 4.3.0". INFERENCE: register your own `AbstractHttpMessageConverter` around Iceberg's `ObjectMapper` rather than extending Spring's Jackson 2 classes.
- **R4. Oracle's JDK 25 certification is new and has known bugs.** Only the 23.26.4.0 download page says "certified with JDK17, JDK19, JDK21, and JDK25". Its footnote adds that "JDK25 certification has three identified bugs; 38927935, 38884897, and 38893494". The Maven POM descriptions still say JDK17/19/21 only. Boot manages 23.26.3.0.0.
- **R5. The installed Docker is old.** Engine 27.1.1 shipped with Docker Desktop 4.33.0 on 2024-07-25. The current release is Docker Desktop 4.98.0, from 2026-11-03. Testcontainers 2.0.5 should work with it, because its default API version is 1.44 and Engine 27.1 supports up to 1.46. INFERENCE only: I did not run anything.
