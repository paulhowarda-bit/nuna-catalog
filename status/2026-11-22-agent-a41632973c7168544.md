# 2026-11-22, the console's settings editor (backlog 141)

The console shows every Iceberg property of a table and a namespace read-only and changes only listed settings that
do something, each with a label, what it does and a value checked in the dialog (D45, amended 2026-11-22). A table
has a new Properties tab; a namespace's is rebuilt; the free-form "Set a property" is gone. Changes go through the
table's commit (`set-properties`, `remove-properties`, asserted on its UUID) and the namespace's properties route.

- Table settings: `write.format.default`, `write.parquet.compression-codec`, `write.parquet.compression-level`,
  `write.target-file-size-bytes`, `write.distribution-mode`, `write.delete.mode`, `write.update.mode`,
  `write.merge.mode`, `write.metadata.metrics.default`, `write.metadata.previous-versions-max`. Namespace: `comment`.
- Left out, with the reason shown beside the property when it is set: `write.metadata.delete-after-commit.enabled`
  (nothing in nuna deletes metadata files on commit; the orphan scan removes those off the log) and a namespace's
  `location` (every table's location comes from its id and the storage profile, never its namespace, D28).
- The namespace subtitle names the governance owner; the catalog's Properties tab links to its maintenance policy.

Checked: `node --check` on the changed modules; the value checks run in node (sizes, ranges, merge-on-read on v1);
the tab and dialog drawn in a static harness, light and dark and at 375 px. `ConsoleSettingsBrowserTest` (heavy) and
the two bites in `bites/UI/` were not run here: the overnight run runs them. After merging main (115f64d), the fast
build passed (`./gradlew build`, 2 m 4 s, `:bitesApply` included, no test failed); it compiles the new browser test
but does not run it.
