# 2026-11-19, the Oracle and MongoDB stores raise StoreUnavailableException for an outage (backlog 7)

Each store classifies a failure in one place, its `Transactions.failed`, as the PostgreSQL store does: a database
that cannot be reached, is failing over or is out of connections is `StoreUnavailableException` (503 with
Retry-After at the routes), anything else a plain `StoreException`. It is used on every path before COMMIT is sent
and by `findCommit`; a failed COMMIT of a write with an id stays `CommitOutcomeUnknownException`. Oracle: ojdbc 23's
`SQLRecoverableException`, Oracle Net errors (SQLState 66000, where a refused connect lands), connection classes,
ORA-03135 and ORA-16000, and a pool's timeout, looked for along the cause chain so UCP's wrapping is seen through.
MongoDB: what the driver's retryable-writes rules retry on, `MongoTimeoutException`, and NoSuchTransaction with the
TransientTransactionError label (a write conflict carries the label too and stays plain). The ORA classes and
SQLStates were taken from ojdbc 23.26.4 and the pools' chains from UCP and HikariCP 7.1.0, each probed on this
machine; the MongoDB codes from driver 5.14's own lists. Only `catalog-store-oracle/`, `catalog-store-mongo/` and
`catalog-store-api/`'s tests changed in code.

Tests: `UnavailableFailuresTest` in both modules (new, Java only: the drivers' own exceptions with their codes and
labels, and each store run against a loopback port that refuses, or accepts and drops, the connection);
`CommitSuite#linkDownBeforeCommitIsACleanFailure` (heavy, all four backends) now requires `StoreUnavailableException`
from commit and read; `MongoStoreSuiteTest#commitWhileFailingOverIsUnavailable` (new, heavy). Bites
`bites/M8/store-outage-not-recognised-oracle.patch` and `-mongo.patch` (the classification answers "not unavailable";
`UnavailableFailuresTest` must fail), checked with `git apply --check`, each file restored with `git checkout`.

Checked: after merging `main`, the shared fast build script (`./gradlew build`): BUILD SUCCESSFUL in 3m 17s, "All
296 bites apply."; the Oracle `UnavailableFailuresTest` 35 of 35 passed and the MongoDB one 28 of 28, the only test
classes either module runs without Docker.
