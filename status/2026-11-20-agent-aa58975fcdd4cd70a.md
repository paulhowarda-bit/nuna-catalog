Paul decided on 2026-11-20 (D17, amended): "Register Trino". Since item 68 a caller that holds nothing in a catalog
gets the missing catalog's 404 on `/v1/config`, and only a registered trusted engine acting as itself sees every
catalog (D18). Trino's own token (user `trino`, client `trino-demo`, group `demo-engines`, which holds no grant) was
not registered anywhere, so the demo's Trino and `deploy/local/run.sh smoke`'s config call would get 404.
