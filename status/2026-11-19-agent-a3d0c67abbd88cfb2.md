# 2026-11-19, names are hidden from callers that hold nothing on them (backlog 14, D18)

it, or (for a namespace) on anything inside it, now gets the 404 a missing one gets, word for word, on every Iceberg
route that names one: HEAD, loads and the metrics route, which the amendment names, and the listings, creates,
registers, commits, drops, renames, unregister, credentials and transactions, which leaked the same way. A caller

one. A rename asks about its source before looking for its destination, and a create table asks before checking the
name's form, so neither answer tells either. Only `catalog-server/` changed in code.
