- `Reconcile.plan`'s check from the watermark judges the journaled versions above it as `DrVerify` does, with the
  same `AddedFiles.firstMissing` and `addsNothing`: after a version that is not whole, one counts only when it adds
  nothing to the newest whole version. The pointer's version must be whole that way for the table to be walked; the
  problem names the first file missing since the newest whole version. A rewound table walks at once.
- `PointerSwap` gains `drWatermark`. `Reconcile.rewind`'s swap sets it, and the stores raise the object's watermark
  to the swap's next version in the commit's transaction, by `recordDrWatermark`'s rule (only rises): `SqlDr.raise`
  (PostgreSQL, CockroachDB), `OracleDr.raise`, `MongoDr.raise`. No schema step. `planRewind` drops its refusal of a
  pointer holding the watermark's metadata "until the verifier passes it": that pointer is now at its watermark.
