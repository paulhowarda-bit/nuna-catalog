# 2026-11-20, the DR reconcile walks with a file check and rewinds views (backlog 28)

Paul's answers on item 28 (D37, amended 2026-11-20), answers 1 and 3, on top of what landed at d176a3b.

- "Walk with a file check": `Reconcile.plan` walks every table as before, watermark or not, then checks each step in
  the store the server runs on (the DR store, in DR): every file the step adds to the version before it (manifest
  lists, the manifests its snapshots add, their data and delete files, statistics files) must be there. It keeps the
  steps before the first that lacks one, takes no tip, and names the missing file in `problem`; a file it cannot read
  stops it the same way. The watermark no longer plays a part in the walk.
- What a version adds is counted once, by `AddedFiles` in catalog-iceberg, for the worker's `DrVerify` and the walk.
  catalog-iceberg is the one catalog module that may import iceberg-core (D2, `IcebergImportBoundaryTest`), and the
  worker depends on it now; its public surface names no iceberg-core type (`PublicSignatureTest`): an opaque
  `TableVersion`, parsed from JSON or read through the caller's `Reader`. `TableFiles` gains `exists` and `bytes`, in
  catalog-objectstore and the server's traced wrapper (spans.md).
- "Rewind views too": `dr-reconcile`'s rewind lists and moves frozen views as tables, under `views` and
  `views-checked`, reading each as its kind's metadata (`Metadata.viewFacts`).
- Tests: `ReconcileFileCheckTest` (new, Java only: an Iceberg client's table in memory and a DR store holding what the
  test copies), `ReconcileWatermarkTest`'s walk cases rewritten and a view rewind added; heavy:
  `MetadataFilesTest#anyFileIsFoundAndRead`, `DrRewindRouteTest#aFrozenViewAboveItsWatermarkIsRewoundToIt` and its
  forward case now expecting the file check's stop.
- Bites in `bites/D37/`: `walk-past-the-watermark` recorded again for the file check, `views-not-rewound` added, and
  `data-files-left-out` (now in `AddedFiles`), `rewind-past-the-watermark` and `rewind-without-freeze` recorded again
  against the moved code with the same breaks.
- Docs: `docs/observability/dr-watermark.md`, the DR runbook in `deploy/README.md` (rewind before walking; the walk
  covers every table), spans.md, build-plan.md. Item 93 added: the DR drill's appender names manifest lists it never
  writes.
