# 2026-11-20, reads on a ref: the catalog@ref prefix, config, loads and listings (backlog 104, D33)

- **The prefix.** `OnRef` and `Prefixes` (catalog-server `rest/`) split `catalog@ref` at the first `@`; no `@`, or
  `@main`, is main. The catalog is found as before (`Holdings.catalog`, hidden names as D18 amended), then the ref
  (`findRef`); a missing ref or a branch past its expiry is 404 `NoSuchWarehouseException`. `CatalogStorage` stops
  startup on a configured catalog name holding `@`.
- **Config.** `/v1/config?warehouse=catalog@ref` answers that prefix, and a tag's 11 read endpoints, a branch's reads
  and three commit endpoints, or main's 26 (`AdvertisedEndpoints.of`).
- **Reads.** Names, namespace listings and table and view listings through the ref's cut (`Lookup`); a branch's own
  pointer, else the cut's (`Lookup.pointer`), read by location with its SHA-256 checked (`CommitEngine.readAt`, which
  `readCurrent` now calls). Table load, HEAD, metrics and credentials; view load and HEAD. The ETag carries the ref's
  id (main's unchanged); `ObjectRead.branch` names the ref; a tag vends read-only credentials.
- **Writes.** On a tag every write is 400 naming the tag; on a branch creates, drops, renames, registrations and
  namespace changes are 400, and commits are 400 until item 105.
- **Tests** (Java only): `RefReadsTest` (14), `CatalogNameTest` (2); `HiddenNamesTest` and `StoreOutageRoutesTest` build
  the routes with `Prefixes`.

  class selected, reverted): ten on `RefReadsTest`, `catalog-name-at-sign-accepted` on `CatalogNameTest`. Ten older
  bites the change moved, recorded again with the same breaks: `D18/config-shows-every-catalog`,
  `D18/default-warehouse-shown-to-outsiders` and `D18/prefix-shows-every-catalog` were seen to bite

  `D13/labels-not-in-etag`, `D13/metrics-for-a-missing-table`, `D13/metrics-unguarded` and
