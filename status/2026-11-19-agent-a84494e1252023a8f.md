# 2026-11-20, the DR replication watermark, its verifier and the rewind (item 28, item 83 folded in; D37)

Item 28 as Paul settled it on 2026-11-20 (D37, amended), in three commits that each build, then the docs. Item 28
stays open until item 92, which holds what is left, lands.

- **Stores.** A DR watermark per table and view, in the catalog database so it reaches DR with it:
  `recordDrWatermark` (only rises, never above the pointer, active objects only; `WATERMARK_BEHIND`,
  `WATERMARK_AHEAD`), `listDrBehind`, `readDrWatermark`, the journal read after a version, purged with its object.
  PostgreSQL V9, CockroachDB V8, Oracle V10, MongoDB step 8. `DrSuite` in each of the four store suites (heavy).
- **Routes** (`DrRoutes`): the verifier's work list and report, for a maintenance principal acting as itself, and
  the operators' readout `GET /management/v1/dr/watermarks`, by name, with each table's lag.
- **The verifier** in the maintenance worker (`DrVerify`, `DrVerifier`, `DrStores`; `WorkerApplication.DrPasses`):
  off until `nuna.maintenance.dr.replicas.<profile>` names a DR store (endpoint, keys, CA bundle) for a storage
  profile; every `nuna.maintenance.dr.verify-interval` (1 minute) it checks each version above the watermark, every
  file it adds, data included, and reports the newest whole one. A table with no watermark is checked whole, in one
  listing. Meters `nuna.maintenance.dr.*`; alerts `NunaDrLagging` (past 15 minutes) and `NunaDrVerifierNotPassing`.
- **The reconcile** (`Reconcile`, `ReconcileRoutes`): the walk stops at the watermark (item 83), and
  `{"rewind": true}` reports each table above its watermark with its lost commits and, with `apply`, moves each
  frozen one back in one journaled commit, the watermark's metadata written again.
- **Docs:** `docs/observability/dr-watermark.md` (new), worker-metrics.md, dashboards-and-alerts.md, the
  observability README, and the DR runbook in `deploy/README.md` ("Recovering in the DR region").
- **Bites,** in `bites/D37/`: `data-files-left-out`, `lower-watermark-accepted`, `rewind-without-freeze`,
  `rewind-past-the-watermark`, `walk-past-the-watermark`. `bites/M8/reconcile-without-freeze`,
  `reconcile-apply-ignores-moved-pointer` and `reconcile-findcommit-answers-at-once` recorded again against the new
  `Reconcile`, with the same breaks.
