# atelier overview

**Purpose.** Atelier (she/her) is the team's UX expert and graphic designer. She reviews and redesigns screens and
flows, rewrites every word on them, and builds offline single-file interactive demos that sell an idea to
executives, business partners or clients.

**Where she came from.** The Atelier demo designer 1.0.0 (`demo_designer_v2.zip`, built 2026-10-29), a
command-line tool that ran the same method through Claude on a corporate Bedrock gateway. In this home, Claude Code
is the brain; the toolkit's knowledge base, vendored libraries and fonts, reference demos and deterministic modules
came across, and its gateway client, prompt templates and pipeline did not (decisions.md).

**What is here.**
- `knowledge/`: 16 design playbooks, a snapshot researched on the open web in October 2026.
- `vendor/`: anime.js 4.5, Lenis, Apache ECharts 6.1, D3 7.9, Three.js r186 (WebGL and WebGPU), 12 variable fonts,
  their licences, and `manifest_v1.json` with each file's sha256.
- `examples/`: three reference demo sources (ledger_live, settlement_desk, effects_gallery); all data simulated.
- `tools/`: `inline` and `check` (REGISTRY.md); three more candidates in BACKLOG.md.

**Current state (v1, 2026-11-21).** Created. Tools tested (17 tests). Not yet used on a real brief.
