# Decision ledger

Branches from `reports/Enterprise Iceberg REST catalog plan.md` (D1–D34). Each branch is OPEN, RESOLVED or BLOCKED-ON. Resolved in the grilling session of 2026-11-06; all 41 branches RESOLVED.

**This ledger supersedes the report where they differ.** Paul's decisions that depart from the report's recommendations:
- D7: four backends (PostgreSQL, CockroachDB, Oracle incl. Exadata/RAC, MongoDB), all in v1. The report's "never: pluggable multi-backend persistence" is overridden. YugabyteDB was a fifth until Paul dropped it on 2026-11-11 (D7's amendment).
- D12: new tables default to v3 (report: v2).
- D28: unlimited namespace depth (report: capped).
- D33: catalog-wide Nessie-style branches, tags and merges, designed in v1 and built next (amended 2026-11-19; first planned for v1.x). The report's "never: long-lived branches and merges" is overridden.
- New since the report: D35 (SingleStore as a client), D36/D36a (one deployment, on-prem or AWS, managing tables on both), D37 (zero loss in-region, async DR).
